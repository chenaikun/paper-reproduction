## 0. 全文一句话

> 检测蒸馏过去都在模仿特征；本文指出 **GFL 早就把定位变成了概率分布**，所以定位知识本来就在输出层，可以直接做 KL；再配一个 **VLR** 选出"值得蒸"的区域，就得到 40.1 → **42.1** AP（COCO，R50 学生），而且**推理零开销**。

三个贡献：**LD 损失** + **VLR 区域** + **在多个检测器上验证**。

---

## 1. Abstract

**这一节讲了四件事：**

1. **现状**：检测蒸馏的主流是 feature imitation（模仿教师中间层特征）。
2. **问题**：特征模仿需要"选在哪蒸、怎么对齐维度"，而且蒸馏信号容易被背景稀释。
3. **做法**：
   - 把边界框表示成**概率分布**（每条边 17 个 bin）；
   - 用**带温度的 KL** 在输出层蒸定位知识（LD）；
   - 用 **VLR** 选出"已经很接近但还不够正样本"的锚点区域。
4. **结果**：GFL-R50 学生 40.1 → 42.1 AP，且学生结构不变（推理无额外开销）。

**一句话**：不是发明新表示，而是**重新解释已有表示**——GFL 的分布本来是为了更好地回归，本文发现它同时是一个现成的蒸馏接口。

## 2. Introduction（第 1 节）

### 2.1 提出问题的逻辑

```text
检测蒸馏 = 让小模型学大模型
        ↓
过去的共识：分类 logit 里没有定位信息，所以只能"抄特征"
        ↓
后果：要选层、要对齐维度、背景噪声稀释信号、还要额外设计
        ↓
本文的观察：GFL 把框回归变成了"每条边的分布"
        ↓
结论：定位信息本来就在 logit 里，只是以前没人这么看
```

### 2.2 三条贡献

| # | 贡献 | 一句话 |
|---|---|---|
| 1 | **LD** | 对四条边的分布做带温度的 KL，直接蒸定位 |
| 2 | **VLR** | 只蒸"差一点"的那一圈锚点，避开背景噪声、又比只用正样本多 |
| 3 | **通用性** | 在 GFL / ATSS / RetinaNet / RepPoints 上都能用，推理零开销 |

### 2.3 图示（Fig.1 / Fig.2）

- **Fig.1**：动机对比——特征模仿 vs logit 模仿的区别（通常画成"蒸馏位置"的示意）。
- **Fig.2**：整体框架——学生和教师各自过 head，Main 区域做 KD+LD，VLR 区域只做 LD。

## 3. Related Work（第 2 节）

### 3.1 检测蒸馏的两条路线

| | Feature Imitation（旧主流） | Logit Mimicking（本文） |
|---|---|---|
| 蒸什么 | 教师中间层 / FPN 特征 | 检测头输出（分类 logits、框分布 logits） |
| 代表 | FitNets、Fine-Grained、DeFeat、GI Imitation | KD（Hinton）+ 本文 LD |
| 优点 | 知识"混"在特征里，看着信息多 | 不需要对齐维度、**推理零开销** |
| 缺点 | 要选位置、要对齐、被背景稀释 | 以前被认为"分类 logit 没有定位信息" |

### 3.2 LQE（定位质量估计）

**这一小节是在给"不确定性"做学术史，为 LD 让位：**

| 粒度 | 做法 | 代表 |
|---|---|---|
| ① 一个标量 | 给每个框打一个"定位质量分" | YOLOv1 的 objectness、IoU-aware、FCOS 的 center-ness |
| ② 每条边一个方差 | 假设高斯，输出 (μ, σ) | Gaussian YOLOv3、Softer-NMS |
| ③ **每条边一个分布** | 17 个 bin 的概率 | **GFL / 本文 LD** |

**作者的评语**：LQE 只是 `a preliminary approach to model localization ambiguity`。

**为什么"初步"**：标量只知道总分、不知道哪条边不准；方差强制假设了单峰高斯，表达不了多峰。

**→ 这一节的作用**：承认需求存在 → 指出表示不够 → 引出"分布"这个更细的粒度。

## 4. Proposed Method（第 3 节）

### 4.1 地基：GFL 已经把框变成了分布（Eq.1）

传统回归输出 4 个坐标（Dirac delta，无法表达不确定性）。GFL 把每条边 `e ∈ {t, b, l, r}` 表示成 `reg_max+1 = 17` 个 bin 上的分布，坐标由期望还原：

```text
ê = ∫ x · Pr(x) dx                    (Eq.1，连续形式)
ê = Σ_{i=0}^{16} i · p_i              (离散形式，代码里的 Integral 层)
```

**分布形状本身就是知识**：

- 尖（几乎全在一个 bin）→ 模型很确定
- 平（摊在多个 bin）→ 边界模糊
- 多峰 → 存在多个合理解释

> 这是整篇论文的地基：**没有分布表示，就没有可以 KL 的对象。**

### 4.2 方法一：LD 损失（Eq.2 / 3 / 4）

把教师和学生的分布都用温度 τ 软化，逐边算 KL：

```text
S(z, τ) = SoftMax(z / τ)                              (广义 softmax)

L_LD^e  = KL( p_S^τ ‖ p_T^τ ),  p^τ = S(z, τ)          (Eq.2/3，单条边)

L_LD    = Σ_{e ∈ {t,b,l,r}} L_LD^e                    (Eq.4，四条边求和)
```

**代码展开**（`LD/mmdet/models/losses/kd_loss.py`）✅：

```python
target  = F.softmax(soft_logits / T, dim=1).detach()
loss    = F.kl_div(F.log_softmax(pred / T, dim=1), target,
                   reduction='none').mean(1) * (T * T)
```

**四个设计点，每个都可能被追问：**

| 设计 | 原因 |
|---|---|
| 用 `{t,b,l,r}` 而不是 `{x,y,w,h}` | 四条边物理含义一致，能约束到同一个区间（0~16 个 stride），分布才好比较 |
| 用 KL 而不是 L1/L2 | 比的是**分布形状**（不确定性），不是期望值；两个不同的平坦分布期望可能相同 |
| 温度 τ = **10**（分类 KD 用 2） | 17 个 bin 的分布本身很尖，温度要大才能把"不确定性"摊开传给学生 |
| 末尾乘 **τ²** | 除以 τ 后梯度被缩小 τ 倍，乘 τ² 补回量级，换 τ 不用重调学习率 |

**τ 的消融（Table 1a）**📄：

| τ | 1 | 5 | **10** | 15 | 20 |
|---|---:|---:|---:|---:|---:|
| AP | 40.3 | 40.9 | **41.1** | 40.7 | 40.5 |

### 4.3 方法二：VLR（Algorithm 1）

**动机**：

```text
全图蒸馏   → 在纯背景上模仿教师的随机分布 = 噪声
只蒸正样本 → 一张图只有几个 ~ 几十个，太少
        ↓
需要"中间地带"：已经很接近、但还不够正样本的那一圈
```

**论文 Algorithm 1**📄：

```text
输入：第 l 层锚点 B_l^a，GT 框 B^gt，正样本阈值 α_pos，比例 γ
1. 算 DIoU 矩阵   X_l[i][j] = DIoU(B_i^a, B_j^gt)
2. 算下界         α_vl = γ · α_pos
3. 取区域         V_l = { (i,j) | α_vl ≤ X_l[i][j] < α_pos }
输出：VLR 区域 V_l
```

**代码里 α_pos 是怎么来的**（`atss_assigner.py:183` `get_vlr_region`）✅：

| 步骤 | 代码行为 | 关键数字 |
|---|---|---|
| ① 定阈值 | 每个 GT 在每层按**中心距离**取最近 9 个锚点 → 5 层共 **45 个候选** → 对它们的 **IoU** 求 **μ+σ** 作为 `α_pos` | `topk=9` |
| ② 画区间 | 用这个阈值去筛**全图**锚点的 **DIoU**，落在 `[0.25·α_pos, α_pos)` 的算 VLR | `γ = 0.25` |
| ③ 给权重 | VLR 锚点的权重 = 它与 GT 的 **IoU** | 判据用 DIoU、权重用 IoU |

**为什么判据用 DIoU、权重用 IoU**：

- DIoU 会惩罚"中心偏得远"的锚点（IoU 对这件事不敏感），适合当**门**；
- DIoU 可能是负数，不能当权重；IoU 天然在 `[0,1]`，适合当**力度**。

**γ 的消融（Table 1c）**📄：

| γ | 1 | 0.75 | 0.5 | **0.25** | 0 |
|---|---:|---:|---:|---:|---:|
| AP | 41.1 | 41.2 | 41.7 | **41.8** | 41.7 |

> γ 越大 VLR 越窄，γ→1 就退化成"只在正样本上蒸馏"。γ=0 相当于没有下界（VLR 变成"DIoU < α_pos 的所有锚点"）。

### 4.4 总损失（Eq.5）

```text
L = λ0·L_cls(C_S, C^gt) + λ1·L_reg(B_S, B^gt) + λ2·L_DFL(B_S, B^gt)   ← 学生自己的 GT 监督
  + λ3·I_Main·L_LD(B_S, B_T) + λ4·I_VL·L_LD(B_S, B_T)                  ← 定位蒸馏（两个区域）
  + λ5·I_Main·L_KD(C_S, C_T) + λ6·I_VL·L_KD(C_S, C_T)                  ← 分类蒸馏（两个区域）
```

其中 `I_Main`、`I_VL` 是**区域指示函数**（0/1）。

**四个开关 × 两类知识 = 8 种组合**，这正是 Table 2 的行数。

**两个反直觉结论**📄：

1. **DFL 这一项可以关掉**——LD 已经是分布级监督，比 DFL 更强。
2. **Table A1**：把 GT 的框回归和 DFL 都去掉、**只用 LD**，R18 反而从 35.8 涨到 **36.4** AP。
   → 意思是"**教师的分布**是比"一个 GT 框"更强的定位监督。

**默认权重**（官方 config）✅：

| 项 | 权重 | T |
|---|---:|---:|
| `loss_cls`（QFL） | 1.0 | — |
| `loss_bbox`（CIoU） | 2.0 | — |
| `loss_dfl` | 0.25 | — |
| `loss_ld` | 0.25 | 10 |
| `loss_ld_vlr` | 0.25 | 10 |
| `loss_kd` | 10 | 2 |
| `loss_kd_neg`（VLR 的 KD） | **0** | 2 |

> `loss_kd_neg` 就是 λ6 项，代码里写成 `0 * self.loss_kd(...)`——算了但不要。论文 Table 2 给了原因：VLR KD 无收益（42.1 → 42.0）。

### 4.5 与 TBR 的对比（Eq.6）

**TBR（Teacher Bounded Regression）** 是一个"用教师做门控"的朴素做法：

```text
L_TBR = λ · L_reg(B_S, B^gt),    仅当  ℓ2(B_S, B^gt) + ε > ℓ2(B_T, B^gt)     (Eq.6)
```

**人话**：在每个位置上比一下学生和教师谁更准，**如果教师更准，就在这个位置额外加一份针对 GT 的回归损失**。

| 项 | 含义 |
|---|---|
| `ℓ2` | 框坐标的欧氏距离（判断谁更准） |
| `L_reg` | GIoU 损失（用来优化） |
| `ε` | 容忍边距，控制"圈多大范围" |

**结果**📄：ε=0.1 时 +0.4 AP、+0.7 AP75——**不是零，是个正经 baseline**。

**但它 sub-optimal 的原因**：

```text
教师的输出：4 条边 × 17 个 bin 的完整分布
                 ↓  TBR 只用到其中 1 bit
得到：          "这个位置该不该加练"
                 ↓
学生学到的：    还是 GT 的硬坐标，只是权重×2
```

**教师的"犹豫"完全被丢掉了。** 这就是"coarse bbox representation"的含义。

> 而且 TBR 只用了 Main 区域（论文原话：`only the main distillation region is adopted`），连 VLR 都没用上。

## 6. Conclusion（第 5 节）

三条收束：

1. **logit 模仿可以打败特征模仿**——前提是找到"值得模仿的定位表示"；
2. **定位知识比语义知识更有效**（+1.0 vs +0.1）；
3. **区域要分开选**：语义在主区域，定位在主区域 + VLR。

**局限（论文自己提的 + 后续被指出的）**：

- 依赖 GFL 这类"分布式回归"的检测器；
- VLR 的阈值依赖 ATSS 的 μ+σ，换个分配器要重新设计；
- 分类蒸馏在本文设置下几乎无收益，原因未深入分析（后来 CrossKD 归因于 target conflict）。

```text
GFL 把框变成分布                 ← 地基（3.1, Eq.1）
        ↓

        ↓
```

## 11. 可能被追问的六个点

**Q1：为什么用 KL 不用 L1？**
L1 比的是"期望差多少"，KL 比的是"分布形状差多少"。两个形状完全不同的分布可以有相同的期望，但 L1 看不出来。

**Q2：为什么四条边分开算，而不是整框一个分布？**
四条边的物理含义一致（都在 0~16 stride 的同一区间），可以共享同一套 bin 语义；整框一个分布的话，四条边的尺度不一样，没法共用 bin。

**Q3：温度为什么是 10 而不是 2？**
17 个 bin 的分布本身很尖（教师常常 0.9 集中在 1 个 bin），τ 太小传不出不确定性。Table 1a：τ=10 最好，15/20 反而降。

**Q4：VLR 和"难例挖掘"有什么区别？**
难例挖掘选的是"loss 大"的样本；VLR 选的是"位置接近但还不够正样本"的样本——它不看你当下的 loss，只看几何关系。

**Q5：为什么不直接把教师的所有输出都蒸？**
背景位置的教师分布接近随机，蒸它等于加噪声。Table 2 的 VLR 消融证明了"扩大区域"要有限度。

**Q6：为什么分类蒸馏几乎没用？**
论文没深挖，只说 +0.1。后续 CrossKD（CVPR 2024）归因于 **target conflict**：同一位置上 GT 目标和教师预测本来就不一致，硬拉会互相抵消。
