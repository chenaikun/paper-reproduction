# LD 核心机制

> 论文：*Localization Distillation for Dense Object Detection*，CVPR 2022
> 工作：在 VOC 上用单卡单 epoch 的 4 组消融，验证论文的机制方向（不是数值复现）

---

## 逻辑

```text
①  检测蒸馏的老做法：让学生模仿教师的深层特征
            ↓  为什么？因为"分类 logit 里没有定位信息，回归的数字没法蒸馏"
②  论文的破局点：GFL 早就把框表示成概率分布（每条边 17 个 bin）
            ↓  那么定位知识本来就在输出层，直接 KL 就行 —— 不用抄特征
③  但全图蒸馏是噪声，只蒸正样本又太少
            ↓  所以再加一个 VLR：只蒸"已经很接近、但还差一点"的那一圈锚点
④  验证方式：4 组变体，只差三个 loss 权重，其余完全一致
            ↓
⑤  结果：只加定位蒸馏 +4.2 AP / +5.7 AP75；只加分类蒸馏 −1.0 AP
            ↓
⑥  边界：这是 1 epoch 的机制验证，支持"方向"，不支持"数值"
            ↓
```

---

## 1. 结论

**定位知识可以蒸馏，而且在输出层就能蒸；它比语义知识更值得蒸。**

我们在 VOC 上得到的证据：

| 变体 | ΔAP | ΔAP75 |
|---|---:|---:|
| 只加分类蒸馏 | **−1.03** | −1.59 |
| 只加定位蒸馏 | **+4.23** | **+5.67** |
| 两个都加 | +2.61 | +2.94 |

排序（定位 ≫ 分类）与论文一致；但**设置与论文不一致，非数值复现**。

---

## 2. 论文

### 2.1 前提：GFL 已经把框变成了分布

传统回归输出 4 个坐标（一个数字）。GFL 把每条边 `{上,下,左,右}` 表示成 **17 个 bin 上的概率分布**，坐标由期望还原：

```
ê = Σ i · p_i     (i = 0..16)
```

**分布形状本身就是知识**：尖 = 模型很确定；平 = 边界模糊；多峰 = 有多个合理解释。

这是论文地基——**没有分布，就没有可以 KL 的对象**。

### 2.2 方法一：LD（定位蒸馏）

把教师和学生的分布都用温度 τ 软化，再逐边算 KL：

```
L_LD = Σ_{e ∈ 4 条边}  KL( softmax(z_S/τ) ‖ softmax(z_T/τ) ) · τ²
```

代码（`kd_loss.py`）：

```python
target  = F.softmax(soft_label / T, dim=1).detach()
kd_loss = F.kl_div(F.log_softmax(pred / T, dim=1), target,
                   reduction='none').mean(1) * (T * T)
```

设计点：

| 设计 | 原因 |
|---|---|
| 用 4 条边，不用 x/y/w/h | 四条边物理含义一致，能约束到同一区间，分布才好比较 |
| 用 KL，不用 L1/L2 | 比的是"分布形状"（不确定性），不是"期望值" |
| τ=10（分类是 2） | 17 个 bin 很尖，温度要大才能把不确定性摊开；末尾乘 τ² 补回梯度量级 |

### 2.3 方法二：VLR（有价值的定位区域）

**动机**：全图蒸馏 = 在纯背景上模仿教师的随机分布，是噪声；只蒸正样本 = 一张图只有几个，太少。需要中间地带。

**做法**（ATSS 的自适应阈值 + 一个下界）：

```
① 每个 GT 在每层取中心最近的 9 个锚点 → 5 层共 45 个候选
② 阈值 α_pos = 这 45 个候选 IoU 的 μ + σ
③ VLR = 全图锚点里 DIoU ∈ [0.25·α_pos, α_pos) 的那些
④ 权重用 IoU（判据用 DIoU）
```

| | 正样本（Main） | VLR |
|---|---|---|
| 选择 | 45 个候选里 IoU ≥ 阈值，且中心在 GT 内 | 全图里 DIoU 落在 `[0.25·thr, thr)` |
| 数量 | 几个 ~ 几十个 | 几百个 |
| 语义 | 已经定位对了 | 已经很接近，但还差一点 |
| 蒸什么 | 分类 KD + 定位 LD | 只做定位 LD |

> 论文 γ=0.25 的消融：γ 越大 VLR 越窄，γ→1 就退化成"只在正样本上蒸馏"，AP 从 41.8 掉到 41.1。

### 2.4 论文关键数字

| 实验 | 结果 |
|---|---|
| COCO 主结果（Table 4） | GFL-R101(44.7) → R18：35.8→**37.5**（+1.7） |
| 高 IoU | R50 AP75：43.1→**45.6** |
| 分离消融（Table 2） | baseline 40.1 / 只 KD 40.2 / 只 LD 41.1 / 全开 42.1 |
| VOC 补充（Table A4） | 51.8→53.0（+1.2） |

## 3. 实践

### 3.1 四组变体，只差三个权重

| 变体 | `loss_kd`(T=2) | `loss_ld`(T=10) | `loss_ld_vlr`(T=10) |
|---|---:|---:|---:|
| Baseline | — | — | — |
| KD-only | 10 | 0 | 0 |
| **Loc-only** | 0 | 0.25 | 0.25 |
| Full | 10 | 0.25 | 0.25 |

所有变体都保留学生自己的 GT 监督（`loss_cls / loss_bbox / loss_dfl`）——这是"只差蒸馏 loss"的准确含义。

### 3.2 约束：未改官方代码

官方仓库是 submodule，改了别人就复现不了。所以：

- 官方代码只打一个 10 个文件的兼容补丁（版本门禁 / NumPy 别名 / 设备与依赖）；
- 实验壳只做三件事：**继承官方配置、用环境变量传超参、subprocess 调官方入口**；
- 5 个变体配置，每个只改 3 个数字。

真正的 loss 在一处：`LDHead.loss_single()`（`ld_head.py:116-282`）。

### 3.3 为了去理解论文，手写了两个脚本

| 我写的 | 对应的官方代码 | 差在哪 |
|---|---|---|
| 手写 KL 蒸馏 | `kd_loss.py` | 我用了**求和**，官方用**平均**（实测正好差 5 倍 = 格子数）；漏了温度 `/T` 和 `×T²` |
| 手写 VLR 区间 | `atss_assigner.py:183` | 阈值写死 0.5，官方是每个 GT 自适应 `μ+σ`；判据 DIoU、权重用 IoU |

两个练习：**定位蒸馏 = 一个 KL（怎么比）+ 一个区域选择（比谁）**。

## 4. 结果

### 4.1 主表（VOC2007 test）

| 模型 | AP | AP50 | AP70 | AP75 |
|---|---:|---:|---:|---:|
| R101 Teacher | 0.3375 | 0.5361 | 0.4088 | 0.3505 |
| R18 Baseline | 0.2404 | 0.4153 | 0.2917 | 0.2354 |
| R18 + KD-only | 0.2302 | 0.3933 | 0.2774 | 0.2194 |
| **R18 + Loc-only** | **0.2828** | **0.4636** | **0.3469** | **0.2921** |
| R18 + Full | 0.2666 | 0.4384 | 0.3252 | 0.2648 |

> AP 口径：VOC 数据、按 COCO 的 IoU 扫描（0.5→0.95 十个阈值平均），插值方式仍是 VOC07 的 11 点。

### 4.2 三个观察

1. **定位蒸馏单独用效果最大**：四个指标全涨，AP75 +5.67。
2. **分类蒸馏单独用是负迁移**：四个指标全掉，AP50 −2.19。
3. **两个加起来不如只用定位**：Full 涨 2.6，但明显不如 Loc-only 的 4.2。

**增益随 IoU 升高而变大**（AP50 +4.8 → AP75 +5.7），这正是"定位蒸馏在改边界质量"应有的效果。

### 4.3 和论文的方向对照

| 对照 | 论文 | 本次 | 一致？ |
|---|---|---|:--:|
| LD 单独 > 不蒸馏 | 41.1 vs 40.1 | 28.3 vs 24.0 | ✅ |
| LD > KD | 41.1 vs 40.2 | 28.3 vs 23.0 | ✅ |
| 高 IoU 收益更多 | AP75 +2.5 | AP75 +5.67 > AP50 +4.84 | ✅ |
| KD 收益很小 | +0.1 | −1.0 | ⚠️ 相反 |

## 5. 解释

### 5.1 定位蒸馏有效（证据 + 机制）

- **监督密度高一个量级**：一个正样本从"4 个坐标"变成"4×17 个概率"。论文 Table A1 更极端：去掉 GT 的框回归和 DFL、**只用 LD**，R18 反而从 35.8 涨到 36.4。
- **软标签带不确定性**：边界模糊的地方教师给平坦分布，学生学到"这里可以有多个答案"，而不是被一个硬坐标拉走。
- **覆盖范围大**：VLR 把几百个"差一点"的锚点也纳入监督。

### 5.2 分类蒸馏掉点（一层机制 + 三个放大器）

```text
放大器（H1~H3）                机制（H4）              结果
权重 10 过大          ┐
教师只训 1 epoch      ├──►   目标冲突   ──►  学生被拉离 GT  ──►  KD-only 掉点
VOC 只有 20 类        ┘
```

**冲突长什么样**（一个正样本位置）：

```
GT 要求：     person = 0.6，其余 19 类 = 0          （权重 1）
教师软标签：  cat = 0.9，person = 0.1               （权重 10）
              ↑ 两条指令方向相反，教师那条还重 10 倍
```

**定位不受影响**：定位上教师通常比学生更接近 GT，两者同向；分类上教师的置信度与 GT 的 0/1 目标在难样本上分歧大。

> 注意：这只是**假设**。后续工作 CrossKD（CVPR 2024）把"目标冲突"量化成了一个已发表的机制，可以作为支撑，但我们自己没有做梯度层面的验证。

### 5.3 Full 为什么不如 Loc-only（纯假设）

KD 和 LD 共享同一套 backbone/FPN，KD 的负迁移可能拖累定位分支的更新方向。

## 6. 边界

**六条硬差异**

| 维度 | 论文 | 本次 |
|---|---|---|
| 数据 | COCO 118k | VOC 16,551 |
| 分辨率 | 1333×800 | 640×384 |
| epoch | 12（COCO）/ 4（VOC） | **1** |
| 教师 | R101 充分训练（44.7 AP） | R101 只训 1 epoch（33.8 AP） |
| 硬件 | 8 卡 | 1 卡 |

**四条方法论局限**

1. **1 epoch 测的是"收敛速度"，不是"最终精度"**——蒸馏在短训练里常表现为加速收敛，这部分收益可能训练充分后消失。这是最重要的一条。
2. **单随机种子**，没有方差估计，不能做显著性判断。
3. **教师欠训练且分辨率不匹配**：教师在 1000×600 上训，学生是 640×384。
4. **VLR 的净贡献没有分离**：Loc-only 同时开了 Main LD + VLR LD，`main-ld-only` 配置已就绪但没跑。
