## 一句话结论

> 论文的核心命题是"**定位知识比语义知识更值得蒸馏，而且可以在输出层（logit）直接蒸馏**"。
> 我们在 VOC 上用单卡、单 epoch 的 4 组消融验证了它的前半句：**只加定位蒸馏，AP +4.2、AP75 +5.7；只加分类蒸馏，AP −1.0**。

## 0. 一分钟版

**问题**：检测蒸馏过去的主流是"让学生模仿教师的深层特征"（feature imitation），而不是模仿输出 logits。原因很实际——分类 logit 里没有定位信息，而定位是回归，一个坐标数字无法"蒸馏"。

**论文的破局点**：GFL 这类检测器早就把边界框表示成了**离散概率分布**（每条边 17 个 bin）。既然教师输出的是分布，那定位知识天然就是可以 KL 的 logit。于是"抄特征"这一步可以省掉，直接在输出层蒸馏。

**两块方法**：

1. **LD（Localization Distillation）**：对边界框 4 条边的概率分布做带温度的 KL。
2. **VLR（Valuable Localization Region）**：不是全图都蒸馏，只蒸馏"离得近但还不够正样本"的那一圈锚点。

**我们做了什么**：

- 不改官方代码，用配置 + 环境变量 + 补丁做了 4 组受控消融（baseline / KD-only / Loc-only / Full），另备好第 5 组 Main-LD-only；
- 先手写最小实现（KL、DIoU、VLR 区间），再和官方 30 行 `loss_single` 逐行对照，确认理解无误；
- 在 1 块 V100S 上跑完单 epoch 机制实验。

**三个数字**（相对 Student Baseline，单位：百分点）：

| 变体 | ΔAP | ΔAP75 |
|---|---:|---:|
| 只加分类蒸馏 KD-only | **−1.03** | −1.59 |
| 只加定位蒸馏 Loc-only | **+4.23** | **+5.67** |
| 两者都加 Full LD | +2.61 | +2.94 |

**一句话边界**：单 epoch 测的是"收敛速度 + 方向"，不是"最终精度"；单随机种子，不能做显著性结论。

## 1. 论文讲了什么

### 1.1 背景：检测蒸馏的两条路线

| | Feature Imitation（旧主流） | Logit Mimicking（本文） |
|---|---|---|
| 蒸馏对象 | 教师中间层/FPN 特征 | 检测头输出（分类 logits、框分布 logits） |
| 代表工作 | FitNets、Fine-Grained、DeFeat、GI Imitation | KD（Hinton）+ 本文 LD |
| 优点 | 知识"混合"在特征里，看起来信息多 | 无需对齐特征维度，**推理零开销** |
| 问题 | 要选"在哪模仿"、要对齐层、蒸馏信号被背景稀释 | 以前被认为"分类 logit 不含定位信息"，收益小 |

论文的立场很明确：**logit 模仿不是不行，是以前没有找到"值得模仿的定位表示"和"值得模仿的区域"**。这两件事正好对应它的两个贡献。

### 1.2 前提：GFL 已经把框变成了分布

传统回归输出 4 个坐标（Dirac delta，只关注真值点，无法表达不确定性）。GFL 把每条边 `e ∈ {t, b, l, r}` 表示成 `reg_max+1 = 17` 个 bin 上的概率分布，坐标由期望还原：

```text
ê = ∫ x·Pr(x) dx            (论文 Eq.1，连续形式)
ê = Σ_{i=0}^{16} i · p_i     (代码里的 Integral 层，离散形式)
```

分布形状本身就是知识：

- **尖**（几乎全在一个 bin）→ 模型对这条边很确定；
- **平**（摊在多个 bin）→ 边界模糊，模型不确定；
- **多峰** → 存在多个合理解释。

**这一步是整篇论文的地基**：没有分布表示，就没有可以 KL 的对象。

### 1.3 方法一：LD loss

把教师和学生的分布都用带温度的 softmax 软化，然后逐边算 KL：

```text
S(z, τ) = SoftMax(z / τ)                        广义 softmax
L_LD^e  = KL( p_S^τ ‖ p_T^τ )                  论文 Eq.2/3，p^τ = S(z, τ)
L_LD    = Σ_{e ∈ {t,b,l,r}} L_LD^e             论文 Eq.4，四条边求和
```

代码里的展开（`LD/mmdet/models/losses/kd_loss.py`）：

```python
target  = F.softmax(soft_label / T, dim=1).detach()
kd_loss = F.kl_div(F.log_softmax(pred / T, dim=1), target,
                   reduction='none').mean(1) * (T * T)
```

四个容易被追问的设计点：

| 设计 | 原因 |
|---|---|
| 用 `{t,b,l,r}` 而不是 `{x,y,w,h}` | 四条边的物理含义一致，可以约束到**同一个区间**（0～16 个 stride），分布才好比较 |
| 用 KL 而不是 L1/L2 | 比的是"分布形状"（不确定性），不是"期望值"；两个不同的平坦分布期望可能相同 |
| 温度 `τ=10`（分类是 2） | 17 个 bin 的分布本身很尖，需要更大的 τ 才能把"不确定性"摊开传给学生。论文 Table 1：τ=1/5/10/15/20 → 40.3/40.9/**41.1**/40.7/40.5 |
| 末尾乘 `T²` | 除以 τ 后梯度被缩小 τ 倍，乘 τ² 补回量级，换 τ 不用重调学习率 |

> **为什么这件事以前没人做**：分布表示（GFL）是为"更好地回归"设计的，没人想过它同时是一个现成的"蒸馏接口"。这是论文最巧的一步——**不发明新表示，只重新解释已有表示**。

### 1.4 方法二：VLR

**动机**：全图锚点做定位蒸馏，等于让模型在纯背景位置上模仿教师的随机分布，是噪声；只在正样本上做，数量又太少（一张图几个到几十个）。需要"中间地带"。

**论文 Algorithm 1**：

```text
输入：第 l 层锚点 B_l^a，GT 框 B^gt，标签分配的正样本阈值 α_pos
1. 算 DIoU 矩阵 X_l[i][j] = DIoU(B_i^a, B_j^gt)
2. 下界 α_vl = γ · α_pos
3. VLR: V_l = { (i,j) | α_vl ≤ X_l[i][j] ≤ α_pos }
```

**官方代码怎么落地**（`LD/mmdet/core/bbox/assigners/atss_assigner.py:183` 的 `get_vlr_region`）：

| 步骤 | 代码行为 | 关键数字 |
|---|---|---|
| ① 定阈值 | 每层按**中心距离**取最近 9 个锚点 → 5 层共 **45 个候选** → 对它们的 IoU 求 **μ+σ** 作为该 GT 的 `α_pos` | `topk=9`，45 个 |
| ② 画区间 | 用这个阈值去筛**全图**锚点的 **DIoU**，落在 `[0.25·α_pos, α_pos)` 的算 VLR | `γ=0.25` |
| ③ 给权重 | VLR 锚点的权重 = 它与 GT 的 **IoU**（判据用 DIoU，权重用 IoU） | 两套口径混用 |

**正样本 vs VLR 的区别**（一张表讲清）：

| | 正样本（Main 区域） | VLR |
|---|---|---|
| 怎么选 | 45 个候选里 IoU ≥ μ+σ 且中心在 GT 内 | 全图锚点里 DIoU ∈ [0.25·thr, thr) |
| 数量 | 几个 ~ 几十个 | 几百个 |
| 语义 | "已经定位对了" | "已经很接近，但还差一点" |
| 蒸馏什么 | 分类 KD + 定位 LD | 只做定位 LD（VLR KD 收益很小） |
| 权重 | 学生自己的质量分 | 与 GT 的 IoU |

> γ 的消融（论文 Table 1c）：γ=1/0.75/0.5/**0.25**/0 → 41.1/41.2/41.7/**41.8**/41.7。γ 越大 VLR 越窄，γ→1 就退化成"只在正样本上蒸馏"。

### 1.5 总损失

```text
L = λ0·L_cls(S, gt) + λ1·L_reg(S, gt) + λ2·L_DFL(S, gt)          ← 学生自己的 GT 监督（必须有）
  + λ3·I_Main·L_LD(S, T) + λ4·I_VL·L_LD(S, T)                    ← 定位蒸馏（两个区域）
  + λ5·I_Main·L_KD(S, T) + λ6·I_VL·L_KD(S, T)                    ← 分类蒸馏（两个区域）
```

四个开关 `I_Main / I_VL` × 两类知识，组合出论文 Table 2 的 8 行消融——**这也正是我们实验矩阵（2.6 节）的理论依据**。

论文还给了两个反直觉结论：**DFL 这一项可以关掉**（LD 已经是分布级监督）；Table A1 更进一步——把 GT 的框回归和 DFL 都去掉、**只用 LD**，R18 反而从 35.8 涨到 36.4 AP，说明"教师的分布"是比"一个 GT 框"更强的定位监督。

### 1.6 论文的关键数字

| 实验 | 设置 | 结果 |
|---|---|---|
| 主结果（Table 4） | GFL-R101(44.7) → R18/R34/R50 | 35.8→**37.5**、38.9→**41.0**、40.1→**42.1**（+1.7 / +2.1 / +2.0 AP） |
| 高 IoU（Table 4） | R50 | AP75 43.1→**45.6** |
| 分离消融（Table 2） | R50，Main 区域 | baseline 40.1；**只 KD 40.2（+0.1）**；**只 LD 41.1（+1.0）**；KD+LD 41.4；**+VLR LD 42.1（+2.0）** |
| VLR KD（Table 2） | 在已有方案上再加 VLR KD | 42.1 → 42.0，**无收益** |
| 对比特征模仿（Table 3） | R50 | GI Imitation 41.5，**本文 42.1** |
| VOC 补充（Table A4） | R18，Main 区域，4 epoch | 51.8/75.8/62.9/**20.6** → 53.0/75.9/64.0/**22.7** |
| Self-LD（Table A2） | 教师=学生 | 仍涨 +0.3～+0.6 AP |
| 推理开销（Table A3） | GFL 系列 | **0 额外开销**（学生结构不变） |

**论文的三条论断**（也是我们要验证的对象）：

1. logit 模仿可以打败特征模仿；
2. 定位知识比语义知识更重要、更高效；
3. 区域要分开选：语义在主区域，定位在主区域 + VLR。

### 1.7 后续：CrossKD（CVPR 2024）把这条线推到了哪

看 LD 之后，我把同组后续的 CrossKD 也读了——它回答了 LD 没有回答的那个问题：

> **LD 回答"蒸什么、在哪蒸"，CrossKD 回答"拿谁当靶子"。**

| 维度 | LD（CVPR 2022） | CrossKD（CVPR 2024） |
|---|---|---|
| 诊断的病因 | prediction mimicking 低效 = 没蒸定位知识 | 低效 = **target conflict**（同一位置上 GT 目标与教师预测矛盾） |
| 解法 | 换蒸馏对象（分布）+ 选区域（VLR） | 换靶子来源（学生中间特征过教师 head 得到 cross-head 预测） |
| 对"区域"的态度 | 在教师-学生差异**中等**的区域蒸（VLR 绕开冲突区） | 冲突区信息量最大，不该绕，应从根上消除冲突 |
| 蒸馏损失 | 分布 KL（T=10） | 分类用 QFL 软标签；GFL 的回归分支直接用 LD 的 KL |
| COCO（R50 学生，1x） | 42.1（论文） | 43.7 |
| R18 学生（基线 35.8） | 37.8 | 38.7 |
| 与 feature imitation | 正交（+GI 42.4） | 正交（+PKD 43.9） |
| 与对方叠加 | — | **CrossKD + LD = 38.1 < 38.7**（重叠，不互补） |

> 口径说明：R18 那一行的 LD 数字取自 CrossKD 论文的复现结果（37.8），与 1.6 节 LD 原文 Table 4 的 37.5 略有差异，属两篇论文设置不同，不是笔误。

三条对我们有用的观察：

1. **同一课题组的两代工作**：LD 一作 Zhaohui Zheng 是 CrossKD 的共作者，Ming-Ming Cheng、Qibin Hou 两边都在。这不是两个独立流派，而是一个组把同一条线做深。
2. **分类蒸馏并非天生有害**：CrossKD 的分支消融里，用 LD 的配方**单独蒸分类**得 37.3（基线 35.8，+1.5），**单独蒸定位**得 36.8（+1.0）。这直接反证"KD-only −1.0"不能归因于"分类知识没用"，更可能是 1 epoch + w=10 + 教师欠训练（4.2 节 H1/H2）。
3. **target conflict 是一个已发表的机制解释**：学生同一个 head 同时被 GT 和教师拉扯，而教师预测与学生的 GT 分配在很多位置本来就不一致；短训练会把这种矛盾放大成负迁移。这比我们 4.3 节"梯度竞争"的说法更具体。

> **别把 CrossKD 说成"LD 的改进版"**：它没有改 LD 的损失，改的是靶子的来源。两者是同一根轴（prediction mimicking）上的两代解法，所以叠加反而掉点。

**为什么不全改官方代码**：官方是 submodule，改了别人 clone 就复现不了；而数据集、分辨率、学习率本来就都是配置。所以壳只做"生成配置 + 启动进程"，官方代码除了打补丁一行不动。

### 2.2 第一层：官方实现里真正重要的 30 行

**(a) 教师怎么挂上去**（`LD/mmdet/models/detectors/kd_one_stage.py`）

- 只取教师 config 的 `model` 键（教师的数据管道、优化器全部丢弃）；
- 教师前向整体包在 `torch.no_grad()` 里，显存只吃激活不吃梯度；
- `teacher_model` 用 `__setattr__` 绕过 `nn.Module` 注册：**不进 `parameters()`（优化器不更新）、不进 `state_dict()`（学生权重文件不含教师）、`.cuda()` 要手动搬**。

**(b) `LDHead.loss_single()` 的三段**（`ld_head.py:116-282`）

```text
pos_inds    = 正样本锚点           （ATSS 标签分配）
remain_inds = VLR 锚点             （get_vlr_region）
（两者可以重叠：一个锚点既可以是正样本，又在 VLR 里）

正样本段：loss_bbox / loss_dfl / loss_ld（教师分布，权重=学生质量分，avg_factor=4）
VLR 段  ：loss_ld_vlr（教师分布，权重=与 GT 的 IoU，avg_factor=16）
分类段  ：loss_kd（教师分类 logits，T=2，w=10）
```

**注意**：所有变体都保留 `loss_cls / loss_bbox / loss_dfl`（学生自己的 GT 监督），这是我们四组消融"只差蒸馏 loss"的准确含义。

### 2.3 第二层：实验壳做的三件事

| 机制 | 做法 | 为什么需要 |
|---|---|---|
| 配置继承 | `_base_` 指向官方 config，子配置只写 3 行权重 | 模型结构一行不抄，避免抄错 |
| 环境变量传参 | `VOC_DATA_ROOT / LD_PROFILE / SAMPLES_PER_GPU / TEACHER_CHECKPOINT` 等 10 个变量 | 官方入口只认 `--cfg-options`，改 10 个嵌套键不可读 |
| 单卡门禁 | `--gpu-ids` 多于 1 个直接退出 | 非分布式的 `MMDataParallel` 不聚合多卡 loss，静默降级会骗人 |
| 补丁三态 | `applied / needed / 冲突则抛异常且一个文件都不改` | 用 `git apply --check --reverse` 判状态，比 grep 字符串可靠 |
| 前置检查 | 教师权重不存在、补丁没打 → 3 秒内报错 | 否则要等训练到第 1 个 iter 才崩 |

### 2.4 第三层（理解层，最重要）：我自己手写的三个练习

这一层不参与训练，但它证明"我不是只会敲命令"。

| 我写的 | 对应的官方代码 | 我写对了什么 | 差在哪 |
|---|---|---|---|
| `练习1_最小定位蒸馏.py` | `kd_loss.py:32` | **KL 的方向对了**（第一个参数 log 概率、第二个概率，很多人会写反）；mask 思路就是 `weighted_loss` 的雏形；用最大绝对误差 `max(S_p − T_p)` 自检收敛 | ① 格子维**求和** vs 官方**求平均**（实测 KL 0.4512 vs 0.0902，**正好差 5 倍 = 格子数**）② 没有 `/T` 和 `×T²` ③ 没有 `detach()` 与 `assert` |
| `算法1_Valuable_Localization_Region.py` | `atss_assigner.py:183` | DIoU 公式 `IoU − ρ²/c²` 对；"选一段区间"的思想对；输出 `(anchor, GT)` 布尔矩阵对 | 阈值是写死的，官方是每个 GT 自适应 `μ+σ`；双重 for 循环要向量化；判据 DIoU 但**权重用 IoU** |
| `练习3_看懂dim.py` | `loss_single` 的 `reshape(-1, 17)` | 讲清 `(N, 68)` → `(N×4, 17)` 之后 `dim=1` 正好是 17 个 bin | —— |
| `练习2_把两个练习拼成loss_ld.py` | `loss_single` 全流程 | 用 80 个锚点拼出迷你 `loss_ld` + `loss_ld_vlr`，跑通"45 候选 → μ+σ 阈值 → 正样本 / VLR" | 规模从 80 个锚点扩到真实输入（640×384 共 5,115 个锚点），还要加质量分权重和 `avg_factor` |
| `画图_锚点与45候选.py` | 汇报用示意图 | 三个坐标系（原图/输入图/特征图）、45 个候选怎么定阈值 | 需要 matplotlib + 中文字体 |

**三个练习串起来就是一句话**：定位蒸馏 = `练习1`（KL）+ `算法1`（选区域），官方代码只是把它们向量化、加上权重和归一化。

```text

   │
   ├─ ① 教师权重存在？→ 否则立刻退出
   ├─ ② build_env()：profile/尺寸/batch/worker/FP16 写进环境变量（不污染 os.environ）

   ▼
build_detector(KnowledgeDistillationSingleStageDetector)
   │    └─ teacher_model ← teacher_config['model'] + teacher_ckpt（不注册为子模块）
   ▼
每个 iteration：
   x   = student.extract_feat(img)
   out_T = teacher.bbox_head(teacher.extract_feat(img))     with torch.no_grad()
```

## 3. 实验结果

### 3.1 协议（四组学生完全一致）

| 项 | 设置 |
|---|---|
| 输入 | 640×384（`tiny` profile） |
| batch / 卡 | 4 / 单卡 |
| epoch | **1**（`LD_REPEAT_TIMES=1`，每轮遍历全部 16,551 张 = 4,138 iter） |
| 精度 | 动态 loss-scale FP16 |
| 学生初始化 | `torchvision://resnet18` |
| 教师 | GFL-R101，1 epoch、1000×600、数据重复 3 次（49,653 iter） |
| 训练中验证 | 关闭，训完统一下载 checkpoint 评估 |
| 学习率 | `0.01 × bs × n_gpu / 16`（官方 LD 公式；bs=4 单卡 → 0.0025） |

### 3.2 主表（VOC2007 test，AP 为 IoU 0.50:0.95 平均）

| 模型 | AP | AP50 | AP70 | AP75 |
|---|---:|---:|---:|---:|
| ResNet-101 Teacher | 0.3375 | 0.5361 | 0.4088 | 0.3505 |
| R18 Student Baseline | 0.2404 | 0.4153 | 0.2917 | 0.2354 |
| R18 + KD-only | 0.2302 | 0.3933 | 0.2774 | 0.2194 |
| **R18 + Loc-only** | **0.2828** | **0.4636** | **0.3469** | **0.2921** |
| R18 + Full LD | 0.2666 | 0.4384 | 0.3252 | 0.2648 |

> **AP 口径**：LD 仓库自带的 `VOCMetric` 会循环 10 个 IoU 阈值（0.5→0.95）各算一次 `eval_map`，PR 曲线按 **VOC07 的 11 点插值**（`dataset == "voc07"` 时代码走 `11points` 分支）。所以 `AP` 列是这 10 个阈值 AP 的平均，`AP50` 列等于原生的 `mAP`。老师若问"这是 COCO AP 还是 VOC mAP"，答案是**VOC 数据、按 COCO 的 IoU 扫描口径算的 AP**——IoU 维度同 COCO，但插值方式和面积分段不是 COCO 的。

### 3.3 相对 Baseline 的变化（百分点，比绝对值更有信息量）

| 变体 | ΔAP | ΔAP50 | ΔAP70 | ΔAP75 |
|---|---:|---:|---:|---:|
| KD-only | −1.03 | −2.19 | −1.43 | −1.59 |
| **Loc-only** | **+4.23** | **+4.84** | **+5.52** | **+5.67** |
| Full LD | +2.61 | +2.32 | +3.35 | +2.94 |

**读法**：Loc-only 的增益随 IoU 阈值升高**单调变大**（AP50 +4.8 → AP75 +5.7），这正是"定位蒸馏改善的是边界质量"该有的样子。

### 3.4 极严格阈值（样本少，只作观察）

| 变体 | AP75 | AP90 | AP95 |
|---|---:|---:|---:|
| Baseline | 0.2354 | 0.0573 | 0.0227 |
| KD-only | 0.2194 | 0.0615 | 0.0234 |
| Loc-only | **0.2921** | 0.0756 | 0.0217 |
| Full LD | 0.2648 | **0.0811** | **0.0416** |

Full LD 在 AP90/AP95 上反而最高——**与论文"分类 KD + 定位 LD 互补"的方向一致**；但 IoU 0.95 下能算作 TP 的框极少，这一列的波动不可靠，只能观察不能下结论。

### 3.5 三个观察

1. **定位蒸馏单独用就有效，而且效果最大**：Loc-only 在全部 4 个指标上都超过 baseline，AP75 提升 5.67 点。
2. **分类蒸馏单独用是负迁移**：KD-only 在全部 4 个指标上都下降，AP50 掉 2.19 点。
3. **两者相加不如只用定位**：Full LD 优于 baseline，但明显不如 Loc-only。**一个合理的解释是**分类蒸馏的负作用抵消了一部分定位蒸馏的收益（第 4.3 节，属假设）。

### 3.6 与论文的方向对照

| 对照项 | 论文（Table 2 / 4 / A4） | 本次 | 是否一致 |
|---|---|---|:---:|
| LD 单独 > 不加蒸馏 | 41.1 vs 40.1（+1.0） | 0.2828 vs 0.2404（+4.2） | ✅ 方向一致 |
| KD 单独收益很小 | +0.1 AP | −1.0 AP | ⚠️ 方向相反 |
| LD > KD | 41.1 vs 40.2 | 0.2828 vs 0.2302 | ✅ |
| 高 IoU 收益 > 低 IoU | AP75 43.1→45.6（+2.5） | AP75 +5.67，AP50 +4.84 | ✅ |
| 论文 VOC 表（Main only） | 51.8 → 53.0（+1.2） | —（未跑 main-ld-only） | ⬜ 待补 |

**能说的**：消融排序（LD ≫ KD）和高 IoU 偏向，两个独立证据都指向同一结论。
**不能说的**：我们的 +4.2 比论文的 +1.2 大，所以我们的方法更好——设置完全不同，见第 5 章。

### 3.7 数值健康检查（蒸馏确实在起作用，不是空跑）

训练前的一次单步 forward/backward 检查：

```text
Student Baseline：loss_cls 0.3744 / loss_bbox 1.1341 / loss_dfl 0.6985 / total 2.2071
Full LD         ：loss_cls 0.0299 / loss_bbox 1.6753 / loss_dfl 0.7499
                  loss_ld 0.0147 / loss_ld_vlr 0.2163 / loss_kd 0.4540 / total 3.1402
```

三项蒸馏 loss 都是**有限值且非零**；`loss_ld_vlr` 比 `loss_ld` 大，符合"VLR 锚点离 GT 更远、分布更难对齐"的预期（两者 `avg_factor` 是 16 vs 4，只作定性比较）。baseline 不含任何蒸馏项，符合消融定义。

## 4. 结果怎么解释

> **原则**：下面每条都标注"这是证据"还是"这是假设"。汇报时不要混着说。

### 4.1 为什么定位蒸馏有效（证据 + 机制）

**证据**：Loc-only 全指标超过 baseline，且增益随 IoU 阈值单调上升（3.3 节）。

**机制解释（三条，按可信度排序）**：

1. **监督密度**：一个正样本的定位监督，从"4 个坐标数字"变成"4×17 个概率"，信息量差一个量级。论文 Table A1 给了更极端的证据：去掉 GT 的 bbox 回归和 DFL、只用 LD，R18 反而从 35.8 涨到 36.4 AP。
2. **软标签带不确定性**：边界模糊的样本，教师给的是平坦分布，学生学到"这里可以有多个答案"，而不是被一个硬坐标强行拉走。
3. **覆盖区域大**：VLR 把几百个"差一点"的锚点也纳入监督，等效于给定位分支加了一个大范围的辅助任务。

### 4.2 为什么分类蒸馏反而掉点（两层：触发条件 + 传导机制）

这四条**不是四个并列的猜想**，而是两层——H4 是机制，H1～H3 是放大它的条件：

```text
触发条件（把冲突放大）              传导机制                 结果
H1 权重 10 过大      ┐
H2 教师只训 1 epoch  ├──► 目标冲突（H4）──► 学生被拉离 GT ──► KD-only 掉点
H3 VOC 仅 20 类      ┘
```

**冲突具体长什么样**（拿你代码里的一个正样本位置举例）：

```text
位置 r 被 ATSS 判为正样本：GT 类别 = person，质量分（与 GT 的 IoU）= 0.6

GT 监督（QFL，权重 1）：   person = 0.6，其余 19 类 = 0
教师软标签（KD，权重 10）：cat = 0.9，person = 0.1
                          ↑ 两条指令方向相反，而教师那条权重是 10 倍
```

注意：你代码里 `loss_kd` 只作用在 `pos_inds` 上，所以冲突**发生在正样本位置**，不在背景。

还有一层更隐蔽的分歧：**即使教师完全判对，软化本身就在制造分歧**。教师对某类有 99.9% 的把握（logit 差 10）时，T=2 的 KD 目标会摊成"正确类 88.6% + 其余 19 类共 11.4%"；而 GT 要求那 19 类严格为 0。温度把教师的尾巴放大了上百倍，这不是 bug，是 KD 的设计——但在强权重下它就变成了持续的拉扯。

**为什么定位蒸馏不吃这个亏**：定位上 R101 教师的框通常比 R18 学生更接近 GT，教师分布与 GT 大体同向，冲突小；分类上教师的置信度与 GT 的 0/1 目标在难样本上分歧大，冲突大。同一个机制，两个相反的结果。

**最小验证（不用重训）**：`analysis/analyze_output_distances.py` 已经算"学生 vs 教师"的分类 L1 和四边分布 L1；再补一个"学生 vs GT"的统计，就能复现 CrossKD Fig.6(b) 的现象——KD-only 离教师更近、离 GT 更远。

| 假设 | 依据 | 怎么验证 |
|---|---|---|
| H1：KD 权重过大（`w=10, T=2`） | 官方默认值是按 COCO 12 epoch 调的；我们只训 1 epoch / 4,138 iter，强约束在早期压制了 GT 分类监督 | 扫 `w ∈ {0, 1, 2, 5, 10}`，看是否单调恶化 |
| H2：教师只训 1 epoch，分类软标签本身噪声大 | 教师按 1000×600 训练，蒸馏时却作用在 640×384 输入上；它的分类置信度未必可靠 | 训 4/16 epoch 教师后重跑 KD-only |
| H3：VOC 只有 20 类，语义知识信息量本来就小 | 论文 Table 2 里 KD 在 COCO（80 类）也只 +0.1 AP；类间关系本来就没多少可迁移的 | 换 COCO 子集或做 80 类实验 |
| H4：**目标冲突**（GT 与教师软标签打架） | CrossKD 量化过：即使同为 GFL+ATSS，大量正样本位置上 GT 目标与教师预测不一致；短训练把冲突放大 | 统计冲突区占比（CrossKD 口径）；或直接换 cross-head 靶子（CrossKD） |

**不能说的**："分类蒸馏没用/有害"——只能说"在单 epoch、w=10、教师欠训练的组合下是负迁移"。

### 4.3 为什么 Full LD 不如 Loc-only（假设）

1. **梯度竞争**：KD 和 LD 都要经过同一套共享的 backbone/FPN，KD 的负迁移会拖累定位分支的更新方向。
2. **训练预算固定**：1 epoch 内两种监督互相挤占"有效更新次数"，短训练放大了这种冲突。

⚠️ **注意**：这只是解释，**没有被证明**。要证明梯度冲突，必须算 `cos(g_gt, g_ld)` 的余弦相似度，而不是看两条 loss 曲线交叉（见第 6 章）。

### 4.4 为什么 AP75 涨得比 AP50 多

AP50 只要求 IoU > 0.5，框"大概套住"就给分，对边界不敏感；AP75/90 要求严丝合缝。定位蒸馏直接作用在**每条边的分布**上，所以收益集中在高阈值——这与论文 VOC 表"AP50 几乎不动（75.8→75.9）、AP90 从 20.6 涨到 22.7"完全同构。

### 4.5 一句话总结第四章

> 在与论文不同的小规模设置下，**定位蒸馏的收益方向、IoU 依赖、以及与分类蒸馏的相对排序都与论文一致**；分类蒸馏的具体表现不同，但可以被"短训练 + 强权重 + 弱教师 + 目标冲突"四个因素解释，且都有可执行的验证方案。

## 5. 边界与局限（必须先说清楚）

### 5.1 与论文的六条硬差异

| 维度 | 论文 | 本次 |
|---|---|---|
| 数据集 | COCO 118k（VOC 仅补充实验） | VOC07+12 共 16,551 张 |
| 输入分辨率 | 1333×800 | 640×384 |
| epoch | 12（COCO 1x）/ 4（VOC） | **1** |
| 教师 | R101，44.7 AP，充分训练 | R101，**1 epoch**，0.3375 AP（且为 1000×600） |
| 硬件 | 8 GPU、每卡 batch 2（**论文未写型号**） | 1×V100S，batch 4 |
| 蒸馏区域 | Main + VLR | Main + VLR（**没有单独跑论文的 Main-only**） |

### 5.2 方法论局限（八条，按严重程度）

1. **1 epoch 测的是收敛速度，不是最终精度**。蒸馏在短训练里常常表现为"加速收敛"，这部分收益可能在训练充分后消失。**这是最重要的一条**。
2. **单随机种子**，没有方差估计。AP 差 0.3～0.5 点完全可能是种子噪声；我们的 ±1～5 点虽大于典型噪声，但没有多 seed 就不能做显著性判断。
3. **教师欠训练且分辨率不匹配**：教师在 1000×600 上训 1 epoch，却给 640×384 的学生当老师，蒸馏信号本身含噪。
4. **VLR 的贡献未分离**：Loc-only 同时开了 Main LD + VLR LD，无法回答"VLR 值不值"。`main-ld-only` 配置已就绪但未跑。
5. **没有 VLR KD 组**：论文的一个重要论点是"VLR KD 无收益"，我们没验证。
6. **没有 self-LD、没有教师质量扰动、没有分辨率扫描**：论文的稳健性和局限分析都没覆盖。
7. **没有梯度层面的证据**：梯度余弦相似度、参数级分析都没做，所以第 4 章的冲突解释只是假设。
8. **权重与原始日志不在仓库里**：checkpoint 和训练日志在云端（`/cloud/cloud-ssd1/ld-runs`），本地只有汇总表；早期评估的终端输出也没单独存盘。

### 5.3 工程债（老师若追问"可复现吗"）

| 问题 | 现象 | 影响 |
|---|---|---|
| 顶层 `img_norm_cfg`/`train_pipeline` 是死键 | 真正生效的是 `data.train.dataset.pipeline` | 改了不生效，容易误判为"调了没用" |
| `loss_im` 权重 0 却仍在算 | 每层跑一次 NMS（5 层 × 每 batch） | 纯浪费算力，不改结果 |
| 合并版 VOC 识别是"猜"的 | 以 `VOC2012/ImageSets/Main/trainval.txt` 是否存在为判据 | 误判时训练集从 16,551 掉到 5,011 且不报错 |

| P3 | self-LD（教师=学生 baseline） | 1 次训练 | 呼应论文 Table A2 的 +0.3～+0.6 |

**判断标准要提前写死**，否则跑完又会"怎么解释都行"：

- 若多 seed 下 Loc-only 的 ΔAP 均值 > 1.5 点且标准差 < 0.5 → 结论可写"稳定有效"；
- 若 `cos(g_gt, g_ld)` 长期 < 0 且集中在 reg head → 4.3 节的假设成立；
- 若 4 epoch 后增益缩小到 < 1 点 → 本次 1 epoch 的收益主要是"加速收敛"，要在结论里改写。

### 7.1 10 分钟讲稿（可直接照读）

先对好"什么时候讲什么、屏幕上放什么"：

**(0:00–1:00) 结论先行**

> "我汇报的是 CVPR 2022 的 LD，定位蒸馏。它要挑战的是检测蒸馏里一个默认做法：大家都去模仿教师的深层特征，因为觉得分类 logit 里没有定位信息。这篇论文说：GFL 早就把框表示成概率分布了，所以定位知识本来就在输出层，直接 KL 就行。
> 我用一张 V100S 在 VOC 上做了四组消融，结论是：**只加定位蒸馏，AP 涨 4.2 点、AP75 涨 5.7 点；只加分类蒸馏，反而掉 1 点**。这个排序和论文一致，但我要先声明，这不是论文数值的复现，设置差得很远。"

**(1:00–3:30) 论文方法（只讲三张图）**

> "先看表示。GFL 把每条边分成 17 个格子，输出一个概率分布，坐标是期望。分布尖就表示模型确定，平就表示它犹豫——这个'犹豫'就是我们要蒸馏的知识。
> 所以 LD 的公式特别简单：把教师和学生的分布都用温度 τ=10 软化，然后算 KL。温度不能小，因为 17 个格子的分布很尖，τ 小了传不出不确定性。
> 第二个组件是 VLR。全图蒸馏等于让模型在背景上学噪声，只在正样本上学又太少。VLR 取的是'已经很接近、但还没达到正样本阈值'的那一圈锚点：先用每层最近的 9 个锚点、5 层共 45 个，算出一个 μ+σ 的阈值，然后把全图里 DIoU 落在阈值 0.25 倍到 1 倍之间的锚点都算 VLR。"

**(3:30–5:00) 代码怎么落地**

> "代码分三块。底下是官方仓库，我一行没改，只打了一个 10 个文件的兼容补丁。中间是我写的实验壳，只做三件事：继承官方配置、用环境变量传超参、subprocess 调官方入口；5 个变体配置就在这一层，每个只改三个 loss 权重。另外还有一组我自己手写的练习，不参与训练，只用来验证理解。
> 为了确认自己真看懂了，我先手写了两个东西：一个 10 行的 KL 蒸馏，一个 VLR 的 DIoU 区间选择，然后和官方那 30 行逐行对照。对照出来三个差异：我用了求和而官方用平均（正好差 5 倍）、我漏了温度和 T²、我没加 detach。这些差异不影响'学得对不对'，但影响数值大小。"

**(5:00–7:30) 结果**

> "主表四组，只差三个权重。baseline 24.0，只加分类蒸馏 23.0，只加定位蒸馏 28.3，两个都加 26.7。
> 三个观察：第一，定位蒸馏单独用效果最大，而且在 AP75 上优势最大，说明它真的在改边界；第二，分类蒸馏单独用是负迁移，四个指标全掉；第三，两个加起来不如只用定位，看起来是分类那部分把收益抵消了一部分。
> 这里的 AP 是在 VOC 上按 COCO 口径算的，0.5 到 0.95 十个阈值取平均。"

**(7:30–9:00) 解释与边界**

> "怎么解释？定位蒸馏的监督密度高一个量级，而且带不确定性；论文补充材料里有个更狠的结论：把 GT 的框回归和 DFL 全去掉、只用 LD，R18 反而从 35.8 涨到 36.4，说明分布级的定位监督比一个 GT 框还强。
> 分类蒸馏为什么掉，我有四个假设：权重 10 太大、教师只训了 1 epoch、VOC 只有 20 类，以及后续工作 CrossKD 指出的"目标冲突"——学生同一个 head 被 GT 和教师同时拉扯。四个都有对应的验证实验，但**现在还不能下结论**。
> 边界我要说清楚：只训了 1 个 epoch，测的是收敛速度不是最终精度；只有单 seed；教师欠训练，而且是 1000×600 训的、作用在 640×384 上；Loc-only 里 VLR 和 Main 是一起开的，VLR 单独的贡献我没测出来。"

**(9:00–10:00) 下一步与请教**

> "下一步优先级：先跑已经配好的 main-ld-only，对齐论文的 VOC 表；再补 2～3 个 seed 看稳不稳；然后扫 KD 权重、算梯度余弦。想请老师指点的有两点：一是 1 epoch 的收益值不值得往 4 epoch 投算力；二是要不要把教师质量扰动做成我们的增量点。"

### 7.3 老师可能问的 13 个问题

| # | 问题 | 回答要点 |
|---|---|---|
| 1 | **这算复现论文吗？** | 不算数值复现，是机制验证。判据是"方向 + 消融排序"一致，不是 AP 对齐。论文 COCO 要 8 卡 12 epoch，我们是单卡 1 epoch。 |
| 2 | **为什么不用 COCO？** | 单卡算力 + 时间。VOC 20 类收敛快，足以看方向；论文自己也在 VOC 上做了补充（Table A4）。 |
| 3 | **教师只训 1 epoch，会不会教师根本没用？** | 教师 AP 0.3375，学生 0.2404，高 9.7 点，满足"教师更强"的前提。但教师欠训练确实压低上限，这是局限第 3 条。 |
| 4 | **KD-only 掉点，是不是实现错了？** | 不是。三项蒸馏 loss 都是有限非零（3.7 节）；同一套代码下 Loc-only 大涨。更可能是权重/教师质量/短训练/目标冲突的组合，见四个假设（尤其 H4）。 |
| 5 | **+4.2 点是不是太多了？** | 1 epoch 下 baseline 严重欠训练，蒸馏有"加速收敛"效应，这部分不等于最终精度增益。所以我说的是"机制方向得到支持"，不是"能涨 4 点"。 |
| 6 | **AP 是什么口径？** | VOC 上按 COCO 口径：10 个 IoU 阈值各算一次再平均；AP50 列等于原生 VOC mAP。 |
| 7 | **VLR 到底贡献多少？** | 目前答不了。Loc-only 同时开了 Main LD 和 VLR LD。已配好 `main-ld-only`，跑完就能分离出来。 |
| 8 | **为什么 τ=10 而不是 2？** | 17 个 bin 的分布很尖，需要更大温度才能把不确定性摊开。论文 Table 1：τ=10 最好（41.1），τ=15/20 反而降。 |
| 9 | **推理有额外开销吗？** | 没有。学生结构完全不变，只是训练时多一次教师前向（`no_grad`）。论文 Table A3 对 GFL 系列是 0 开销。 |
| 10 | **你提到梯度冲突，有证据吗？** | 没有，只是假设。要算 `cos(g_gt, g_ld)`，分模块算。已经列进 P1，不能拿 loss 曲线交叉当证据。 |
| 11 | **这些代码是你写的吗？** | 主体是 AI 辅助生成的，我的理解靠三个手写练习验证：KL 蒸馏、VLR 的 DIoU 区间、dim 的语义。练习1 的 KL 和官方只差"求和 vs 平均、温度、detach"三处，这个差距是我自己对照出来的。 |
| 12 | **这项工作有什么增量？** | 三块：① 单卡可复现的机制验证协议（含 5 个变体配置和自检脚本）；② 教师质量扰动的实验设计（论文没做）；③ 对"1 epoch 蒸馏收益 = 加速收敛"这一解释的实证检验（P2）。 |
| 13 | **你既然看了 CrossKD，为什么停在 LD？** | 同一课题组的两代工作：LD 管"蒸什么/在哪蒸"，CrossKD 管"靶子从哪来"。CrossKD 对 GFL 的回归分支直接用了 LD 的 KL，并把 LD 的 VLR 视为"绕开冲突区"的妥协。选 LD 是因为它只要 MMDet 2 + 单卡就能验证机制；而 CrossKD 指出的 target conflict 正好解释了我们 KD-only 的负迁移（1.7 节）。 |

### C. 术语表

| 术语 | 一句话 |
|---|---|
| **LD** | Localization Distillation，对边界框四条边的概率分布做 KL 蒸馏 |
| **VLR** | Valuable Localization Region，DIoU 落在 `[0.25·thr, thr)` 的锚点集合 |
| **Main 区域** | 标签分配得到的正样本位置 |
| **GFL** | Generalized Focal Loss 检测器，把框回归改写成分布 + 期望 |
| **reg_max / bin** | 分布格子数上界，本实验 16 → 每条边 17 个 bin |
| **DFL** | Distribution Focal Loss，GFL 里训练分布的损失 |
| **τ（温度）** | 蒸馏软化系数，LD 用 10，分类 KD 用 2 |
| **γ** | VLR 下界比例，`α_vl = γ·α_pos`，本实验 0.25 |
| **ATSS** | 自适应标签分配，用 μ+σ 定正样本阈值 |
| **DIoU** | IoU 加中心距离惩罚，VLR 的判据 |
| **avg_factor** | MMDet 里 loss 的归一化分母，`loss_ld` 是 4，`loss_ld_vlr` 是 16 |
| **负迁移** | 教师知识反而让学生变差 |
