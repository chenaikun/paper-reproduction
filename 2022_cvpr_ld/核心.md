> 本文保留为选题阶段的设计记录，不代表最终执行配置。实际实验已改为
> V100S 32GB、GFL-R18 student、GFL-R101 teacher、VOC07+12 和单轮
> 机制验证；当前环境、命令与结果请以
> [ld_core_experiment/README.md](ld_core_experiment/README.md) 和
> [one_epoch_mechanism_results.md](ld_core_experiment/one_epoch_mechanism_results.md)
> 为准。下文中的 RTX 3050、R34/R50 teacher 和小数据子集方案仅作为历史方案。

## 1. 实验目标

本实验不追求复现 LD 在 COCO 数据集上的绝对 AP 数值，而是希望在 RTX 3050 4G 显存条件下验证以下问题：

1. LD 是否能够将教师模型的定位分布信息传递给学生模型；
2. 分类蒸馏、定位蒸馏和 GT 检测监督分别发挥什么作用；
3. 定位蒸馏是否能够改善学生模型的边界框质量；
4. 检测监督和蒸馏监督之间是否存在梯度方向冲突；
5. LD 在什么条件下有效，以及它有哪些局限性。

因此，本实验的准确定位是：

> LD 核心机制与局限性的低资源复现。

这不是 COCO 官方配置和论文数值的严格复现。

---

## 2. LD 方法概述

LD，即 Localization Distillation，中文通常称为定位蒸馏。

LD 的关键并不是简单地对教师模型和学生模型的特征使用 KL 散度，而是利用检测器输出的边界框分布进行定位知识蒸馏。

传统边界框回归通常直接预测：

```text
x_left, y_top, x_right, y_bottom
```

而 GFL 等检测器会将边界框坐标表示为离散概率分布。例如，对于左边界坐标，模型不是直接输出一个数，而是输出多个离散位置的概率：

```text
P(x_left = 0), P(x_left = 1), ..., P(x_left = n)
```

这种分布可以表达定位不确定性：

- 分布尖锐：模型对边界位置比较确定；
- 分布平坦：模型对边界位置存在较大不确定性；
- 分布出现多个峰值：可能存在多个合理的定位位置。

LD 的核心思想是让学生模型学习教师模型的定位分布，而不仅仅是学习教师给出的最终边界框坐标。

---

## 3. 与官方 LD 的区别

官方 LD 主要基于以下配置：

```text
数据集：MS COCO
检测器：GFLv1
学生：ResNet-50
教师：ResNet-101
输入分辨率：约 1333 × 800
训练规模：多 GPU
```

RTX 3050 4G 不适合直接运行完整官方配置。因此，本实验采用低资源改造：

```text
数据集：PASCAL VOC
检测器：GFL 或兼容的分布式边界框回归检测器
学生：ResNet-18
教师：ResNet-34 或 ResNet-50
输入分辨率：短边 480 或 600
batch size：1
混合精度：开启 AMP
```

该改造会影响最终精度，但不会改变实验的核心研究问题。

需要注意：

- VOC 上的结果不能直接与 COCO 上的 AP 比较；
- ResNet-34 到 ResNet-18 是低显存实验配置，不是官方主配置；
- 只有实现了边界框分布蒸馏，才可以称为 LD 核心机制复现；
- 如果只是增加一个普通 KL loss，只能称为 LD 思路演示。

## 4. 最小实验配置

### 4.1 数据集

推荐使用 PASCAL VOC。

原因：

- 类别数量较少；
- 图片分辨率通常低于 COCO；
- 数据准备相对简单；
- 适合快速进行多组消融；
- 足以观察定位蒸馏的基本现象。

建议先使用 VOC 2007 + VOC 2012 的训练集，并使用 VOC 2007 test 进行评估。

如果显存或训练时间仍然紧张，可以先使用较小的数据子集验证代码和实验逻辑。

---

### 4.2 学生和教师模型

推荐配置：

```text
Teacher：GFL + ResNet-34
Student：GFL + ResNet-18
```

如果 ResNet-34 教师能力不足，可以使用：

```text
Teacher：GFL + ResNet-50
Student：GFL + ResNet-18
```

教师模型必须先单独训练，不能直接使用未训练或欠训练的教师。

在进入蒸馏实验前，应确认：

```text
AP_teacher > AP_student
```

同时最好观察：

```text
AP75_teacher > AP75_student
```

因为 LD 主要作用于定位，AP75 比 AP50 更适合观察定位质量变化。

---

## 5. 训练目标

学生模型的总损失可以写成：

```text
L_total =
    L_gt
    + λ_cls * L_cls_kd
    + λ_loc * L_loc_ld
```

其中：

- `L_gt`：学生模型自己的 GT 检测损失；
- `L_cls_kd`：分类 logits 蒸馏损失；
- `L_loc_ld`：定位分布蒸馏损失；
- `λ_cls`：分类蒸馏权重；
- `λ_loc`：定位蒸馏权重。

`L_gt` 不能在正常消融实验中被去掉。否则比较的就不再是“是否使用 LD”，而是“是否使用基本检测监督”。

---

## 6. 核心消融实验

建议至少进行以下四组实验。

| 实验 | GT 检测损失 | 分类蒸馏 | 定位 LD | 目的 |
|---|---:|---:|---:|---|
| Student Baseline | 有 | 无 | 无 | 测量学生模型基础能力 |
| Classification KD | 有 | 有 | 无 | 观察分类知识蒸馏效果 |
| Localization LD | 有 | 无 | 有 | 单独验证定位分布蒸馏 |
| Full LD | 有 | 有 | 有 | 验证完整组合效果 |

### 6.1 Student Baseline

```text
L_total = L_gt
```

该实验用于确定学生模型在没有蒸馏时的基础性能。

必须先得到可靠的 baseline，否则后续无法判断蒸馏是否真正有效。

---

### 6.2 Classification KD

```text
L_total = L_gt + λ_cls * L_cls_kd
```

该实验只蒸馏教师的分类输出，不蒸馏定位分布。

它用于回答：

> LD 的收益是否主要来自分类知识，还是来自定位分布知识？

---

### 6.3 Localization LD

```text
L_total = L_gt + λ_loc * L_loc_ld
```

该实验只使用定位分布蒸馏。

它是验证 LD 核心机制最重要的一组实验。

如果该实验相对于 Student Baseline 在 AP75、bbox IoU 或定位误差方面有所改善，说明定位分布蒸馏确实传递了有效信息。

---

### 6.4 Full LD

```text
L_total =
    L_gt
    + λ_cls * L_cls_kd
    + λ_loc * L_loc_ld
```

该实验同时使用分类蒸馏和定位蒸馏。

它用于观察：

- 分类知识和定位知识是否互补；
- 完整方法是否优于单独的分类蒸馏；
- 完整方法是否优于单独的定位蒸馏；
- 分类蒸馏是否会削弱定位蒸馏效果。

---

## 7. 需要记录的指标

### 7.1 检测指标

建议记录：

```text
mAP
AP50
AP75
AP_small
AP_medium
AP_large
```

VOC 或低分辨率设置下，部分指标可能不稳定，因此不能只根据一次实验下结论。

重点关注：

```text
AP75
bbox IoU
定位误差
```

LD 主要作用于定位分布，因此 AP75 通常比 AP50 更具有参考价值。

---

### 7.2 各项损失

训练过程中分别记录：

```text
L_gt_cls
L_gt_bbox
L_cls_kd
L_loc_ld
L_total
```

重点观察以下现象：

1. `L_loc_ld` 是否持续下降；
2. 加入 LD 后，`L_gt_bbox` 是否下降更快；
3. 总 loss 下降时，AP75 是否同步改善；
4. 定位蒸馏是否导致学生过度模仿教师；
5. 蒸馏权重过大时，GT 检测损失是否反而变差。

需要注意：

> 蒸馏损失下降，并不一定代表检测性能提升。

学生可能只是越来越接近教师，但教师在某些样本上可能是错误的。

## 8. 定位分布分析

为了验证 LD 是否真正传递了定位分布信息，需要对教师和学生的边界框分布进行直接比较。

对于同一批正样本，记录：

```text
教师定位分布
学生定位分布
使用 LD 后的学生定位分布
```

可以计算以下指标：

```text
KL(teacher || student)
分布熵
期望边界坐标
预测框 IoU
边界坐标误差
```

### 8.1 KL 散度

```text
KL(P_teacher || P_student)
```

用于衡量学生定位分布与教师定位分布之间的差异。

如果 LD 有效，训练过程中该差异通常应有所下降。

---

### 8.2 分布熵

```text
H(P) = -Σ P(x) log P(x)
```

熵可以用于观察教师和学生对定位结果的不确定性。

需要分析：

- 学生是否学习到了教师的分布形状；
- 学生是否在边界模糊样本上保留了合理的不确定性；
- LD 是否错误地让学生输出过于尖锐的分布。

---

### 8.3 期望边界坐标

根据离散分布计算期望坐标：

```text
E[x] = Σ x_i * P(x_i)
```

然后比较：

```text
教师期望坐标
学生期望坐标
真实 GT 坐标
```

这可以区分以下情况：

- 学生接近教师，同时也接近 GT；
- 学生接近教师，但远离 GT；
- 学生没有真正学习到教师分布。

---

## 9. 梯度冲突分析

仅观察两条 loss 曲线，不能直接证明存在损失冲突。

如果要研究 GT 检测监督与定位蒸馏之间是否存在冲突，建议计算两者对共享参数的梯度方向。

定义：

```text
g_gt = ∇θ L_gt
g_ld = ∇θ L_loc_ld
```

计算余弦相似度：

```text
cos(g_gt, g_ld)
=
(g_gt · g_ld)
/
(||g_gt|| ||g_ld||)
```

解释如下：

| 余弦相似度 | 含义 |
|---:|---|
| 大于 0 | 两个目标总体方向一致 |
| 接近 0 | 两个目标相互影响较弱 |
| 小于 0 | 存在梯度方向冲突 |

建议分别在以下模块上计算：

```text
Backbone
FPN
Classification Head
Regression Head
```

因为冲突可能只存在于某一个模块。

例如：

- backbone 上两个目标方向一致；
- bbox head 上两个目标方向相反；
- 分类 head 基本不受定位蒸馏影响。

### 注意事项

梯度分析需要分别计算各个损失的梯度，不能先把损失相加后再计算。

伪代码示意：

```python
optimizer.zero_grad()
loss_gt.backward(retain_graph=True)
grad_gt = collect_gradients(model)

optimizer.zero_grad()
loss_ld.backward(retain_graph=True)
grad_ld = collect_gradients(model)

cosine = cosine_similarity(grad_gt, grad_ld)
optimizer.zero_grad()
```

实际实现时需要注意：

- 保留计算图；
- 不要让分析梯度影响真正的 optimizer step；
- 对没有梯度的参数进行过滤；
- 保持两次前向和反向使用相同的数据。

## 10. LD 局限性实验

### 10.1 教师错误传播

设置三种教师：

```text
正常训练的教师
欠训练教师
加入预测噪声的教师
```

观察学生模型表现。

重点分析：

- 教师定位错误是否会被学生继承；
- 教师置信度低时，是否仍然产生过强蒸馏信号；
- LD 是否会让学生远离真实 GT；
- 定位蒸馏对教师质量是否敏感。

这可以验证 LD 的一个重要局限：

> 教师错误可能通过定位分布蒸馏传播给学生。

---

### 10.2 蒸馏权重敏感性

固定其他条件，只改变定位蒸馏权重：

```text
λ_loc = 0
λ_loc = 0.25
λ_loc = 0.5
λ_loc = 1.0
λ_loc = 2.0
```

可能出现的趋势：

```text
权重过小：
LD 信号太弱，效果不明显。

权重适中：
定位分布得到有效传递，AP75 或 bbox IoU 改善。

权重过大：
学生过度模仿教师，GT 监督受到压制，性能下降。
```

该实验用于观察 LD 对超参数的依赖。

---

### 10.3 教师和学生的模型差距

比较以下配置：

```text
ResNet-34 -> ResNet-18
ResNet-50 -> ResNet-18
ResNet-18 -> ResNet-18
```

其中最后一组可以用于观察 Self-LD。

需要分析：

- 教师更强是否一定带来更大收益；
- 教师和学生差距过大时，学生是否难以吸收教师分布；
- 教师和学生能力接近时，蒸馏是否收益有限；
- Self-LD 是否仍然有效。

可能的结论是：

> 教师模型并不是越强越好。教师输出必须既具有更好的知识质量，又处于学生能够吸收的范围内。

---

### 10.4 输入分辨率依赖

比较：

```text
640 × 480
800 × 600
较高输入分辨率
```

重点观察：

- 小目标样本上的定位蒸馏是否失效；
- 低分辨率是否导致教师本身丢失定位信息；
- 学生是否只是学习到了教师的低分辨率误差；
- LD 的提升是否依赖较高输入分辨率。

如果低分辨率下教师的定位结果本身不准确，那么学生蒸馏到的也可能只是低质量知识。

---

### 10.5 蒸馏区域选择

如果实现了 VLR，可以比较：

```text
全区域蒸馏
GT Box 内蒸馏
Main Distillation Region
Valuable Localization Region
```

该实验用于分析为什么 LD 不能简单地对所有位置进行蒸馏。

可能存在噪声的区域包括：

- 背景区域；
- 教师低置信度区域；
- 教师和 GT 不一致的区域；
- 低质量候选框区域；
- 多个目标重叠的区域。

区域选择的作用是尽量保留有价值的定位知识，减少无效或错误蒸馏。

## 11. 推荐实验顺序

### 阶段一：验证检测器

1. 配置并检查 VOC 数据集；
2. 训练 ResNet-18 学生 baseline；
3. 训练 ResNet-34 或 ResNet-50 教师；
4. 确认教师性能优于学生；
5. 检查预测框和分类结果是否正常。

---

### 阶段二：验证蒸馏实现

1. 先只实现分类蒸馏；
2. 再实现定位分布蒸馏；
3. 检查教师参数是否被冻结；
4. 检查教师和学生的特征层级是否正确对齐；
5. 检查教师定位分布是否能够正常生成；
6. 检查 `L_loc_ld` 是否为有限值；
7. 确认蒸馏损失不会产生 NaN 或 Inf。

---

### 阶段三：完成核心消融

依次训练：

```text
Student Baseline
Classification KD
Localization LD
Full LD
```

每组实验建议至少运行两次，以避免单次随机种子造成误判。

记录：

```text
最终 mAP
AP50
AP75
最佳 epoch
各项 loss
训练时间
显存占用
```

---

### 阶段四：分析冲突和缺陷

依次进行：

```text
梯度余弦相似度分析
蒸馏权重实验
教师质量实验
教师-学生差距实验
输入分辨率实验
蒸馏区域实验
```

不需要一开始就完成所有实验。先确保核心四组消融能够稳定运行。

## 12. RTX 3050 4G 的工程配置

推荐设置：

```text
batch size：1
AMP：开启
输入短边：480 或 600
最大长边：640 或 800
学生：ResNet-18
教师：ResNet-34
num_workers：根据内存设置为 2 或 4
```

如果仍然 OOM，可以依次尝试：

1. 降低输入分辨率；
2. 减小最大长边；
3. 关闭不必要的中间特征缓存；
4. 使用梯度检查点；
5. 教师前向使用 `torch.no_grad()`；
6. 确保教师模型处于 `eval()` 模式；
7. 确认没有保存教师反向计算图；
8. 再考虑梯度累积。

教师前向应类似：

```python
with torch.no_grad():
    teacher_outputs = teacher(images)
```

教师模型应被冻结：

```python
teacher.eval()

for parameter in teacher.parameters():
    parameter.requires_grad = False
```

## 13. 关于梯度累积

梯度累积可以降低单次显存占用，但它不完全等价于更大的真实 batch size。

原因包括：

- BatchNorm 统计仍然基于单张图片；
- optimizer 更新频率发生变化；
- 学习率调度需要同步调整；
- 梯度裁剪时机可能发生变化；
- 随机增强对每个小 batch 的影响不同。

因此，推荐顺序是：

```text
先使用 batch size=1 跑通实验；
再根据需要增加梯度累积；
最后重新检查学习率和训练 schedule。
```

## 14. 常见误判

### 14.1 Loss 下降不等于 LD 有效

`L_loc_ld` 下降只能说明学生更接近教师，不能说明学生更接近真实 GT。

必须同时观察：

```text
AP75
bbox IoU
定位误差
教师与 GT 的差异
学生与 GT 的差异
```

---

### 14.2 Loss 曲线交叉不等于梯度冲突

两个 loss 曲线发生交叉，只能说明两个损失的数值变化不同。

要证明梯度冲突，应计算：

```text
cos(g_gt, g_ld)
```

并观察其是否长期或阶段性小于 0。

---

### 14.3 VOC 结果不能等同于 COCO 结果

VOC 和 COCO 在以下方面不同：

- 类别数量；
- 图片数量；
- 目标密度；
- 小目标比例；
- 标注分布；
- 评估指标和难度。

因此，本实验结论应描述为：

> 在 VOC 和低资源设置下观察到 LD 的机制现象。

不能直接写成：

> LD 在 COCO 上能够获得论文中的 AP 提升。

---

### 14.4 更强教师不一定总是更好

如果教师输出错误或过于复杂，学生可能难以吸收。

教师的作用不是提供绝对正确的标签，而是提供额外的软知识。因此：

- 教师质量过低，蒸馏信号不可靠；
- 教师和学生差距过大，学生可能无法学习；
- 蒸馏权重过高，可能压制 GT 学习；
- 教师预测与真实目标冲突时，可能导致负迁移。

---

### 14.5 降低分辨率可能改变实验结论

低分辨率虽然可以降低显存占用，但也可能：

- 丢失小目标；
- 破坏边界细节；
- 让教师定位分布变得不可靠；
- 放大量化误差；
- 使 AP75 波动变大。

因此，输入分辨率应作为实验变量单独记录，而不是忽略其影响。

---

## 15. 推荐结论模板

实验完成后，可以按照以下结构总结：

> 本实验在 PASCAL VOC 数据集上，使用 GFL 检测器和轻量化 ResNet-18/ResNet-34 教师-学生结构，对 Localization Distillation 的核心机制进行了低资源复现。实验不追求复现 COCO 上的绝对 AP，而是重点考察定位分布蒸馏对学生检测器的影响。
>
> 通过 Student Baseline、Classification KD、Localization LD 和 Full LD 四组消融，分别分析了 GT 检测监督、分类知识蒸馏和定位分布蒸馏的作用。实验同时记录 AP50、AP75、定位分布 KL 散度、分布熵以及不同损失对共享参数产生的梯度余弦相似度。
>
> 如果 Localization LD 相对于 Student Baseline 能够改善 AP75、bbox IoU 或定位误差，并且学生定位分布更接近教师和真实 GT，则可以认为 LD 的核心定位知识传递机制得到了验证。
>
> 进一步通过教师错误、蒸馏权重、模型容量差距、输入分辨率和蒸馏区域实验，分析 LD 对教师质量、超参数、分辨率和区域选择的依赖。若教师质量下降或蒸馏权重过大导致学生性能下降，则说明 LD 存在教师错误传播和监督权重敏感等局限。
