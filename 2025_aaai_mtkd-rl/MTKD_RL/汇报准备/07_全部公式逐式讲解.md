# 全部 14 个公式：它在算什么，张量怎么变，汇报怎么说

依据用户 PDF 正文 Eq. (1)–(8) 与附录 A.1 Eq. (9)–(14)。公式按原有编号讲解；为排版清楚，部分仅改变下标位置。论文未明确的地方保留歧义，不默认为正确的标准算法。

## 0. 读公式前统一符号

| 符号 | 含义 | 应避免的混淆 |
|---|---|---|
| i / m / c | 样本、教师、类别索引 | 归一化沿教师维还是样本维必须写清 |
| S / T_m | 学生、第 m 个教师 | 教师固定，不随本轮学生反向更新 |
| y_i | 真实类别 | 代码是形状 [B] 的类别整数 |
| y_i^S、y_i^{T_m} | 论文用于预测输出的记号 | 原文称 logits；计算 CE/KL 时实际要经过对应概率处理 |
| F、f | 用于蒸馏的特征、用于 state 的向量 | 实际代码 F 是空间特征图，f 是全局池化向量 |
| α / β | logit/feature KD 的总体权重 | 不是各教师相对权重 |
| w_l / w_f | logit/feature 侧的教师权重 | 每个样本各两套 M 维向量 |
| θ / η | agent 参数、更新学习率 | 不要与学生优化器的参数和学习率混写 |
| γ | 三分支融合系数 | 此处不是 RL 的折扣因子 |

## Eq. (1)：一个老师时，学生要学三件事

\[
\mathcal L_{KD}
=H(y_i^S,y_i)
+\alpha D_{KL}(y_i^S,y_i^T)
+\beta D_{dis}(F_i^S,F_i^T).
\]

**位置：** PDF p.3 / Preliminary of Multi-Teacher KD。

第一项对真实标签做分类监督，避免学生只模仿教师而脱离任务。第二项模仿教师输出的类别分布，包含不同类别之间的软关系。第三项让中间表示接近教师。

**形状：** logits 各 [B,C]；CE 与 unreduced KL 各 [B]；特征对齐后逐样本 MSE 为 [B]。三项逐样本相加后，训练时再对 B 求均值得标量。

**实际实现：** 默认使用 KD 与 MSE，α=1、β=5。如果教师与学生的通道数或空间大小不同，必须先对齐，不能直接相减。

**上台讲法：** “学生同时学标准答案、老师的判断分布和老师的表示方式。”

## Eq. (2)：从一位老师变成多位老师

\[
\mathcal L_{MTKD}
=H(y_i^S,y_i)
+\alpha\sum_{m=1}^{M}w^m_{l,i}D_{KL}(y_i^S,y_i^{T_m})
+\beta\sum_{m=1}^{M}w^m_{f,i}D_{dis}(F_i^S,F_i^{T_m}).
\]

**位置：** PDF p.3。

CE 只算一次；教师相关的两项分别加权求和。本文主要研究怎样得到两套 w，而不是重新发明全部 KD 损失。

**关键维度：**

~~~text
KL[B,M] * Wl[B,M] → sum(M) → [B]
MSE[B,M] * Wf[B,M] → sum(M) → [B]
加CE[B] → mean(B) → scalar
~~~

**小例子：** 第一张图的两套权重是 Wl=[.4843,.3160,.1997]，Wf=[.3963,.4284,.1753]。因此输出侧最信任 T1，特征侧最重视 T2。总损失为 0.9163+0.1476+5×0.1793≈1.9602。

**注意：** 不要先平均全部样本的 KL 再乘逐样本权重，那样失去样本对应关系。不同教师的损失量级也可能不同，权重相同不意味着梯度贡献相同。

**上台讲法：** “本文把问题转化为对每个样本分别分配输出知识和特征知识的教学强度。”

## Eq. (3)：用余弦看特征方向是否接近

\[
cos_i^{T_m}
=\frac{r(f_i^S)\cdot f_i^{T_m}}
{\|r(f_i^S)\|_2\|f_i^{T_m}\|_2}.
\]

**位置：** PDF p.3 / State 第4项。

r 将学生向量变成教师的维度。分子是内积，分母消除向量长度的影响。非零向量情况下，cosine 越大代表方向越相似。

**形状：** 学生 [B,d_s]，对齐后 [B,d_m]，教师 [B,d_m]，沿通道计算得到 [B]，代码再 unsqueeze 成 [B,1]。

**小例子：** [1,0,0] 与 [1,.2,0] 的 cosine 为 1/√1.04≈0.9806；与 [0,1,0] 的 cosine 为0。

**边界：** cosine 不等于 MSE。向量 [1,0] 与 [10,0] cosine=1，但 MSE 大。论文写线性 regressor；公开代码对特征图先做插值/池化，再用 Conv1×1+BN+ReLU，之后池化成向量，二者实现层次不同。

**上台讲法：** “这个量回答学生当前的表示方向与哪位教师更接近。”

## Eq. (4)：用 KL 看输出分布差多远

\[
KL_i^{T_m}=D_{KL}(y_i^S,y_i^{T_m}).
\]

**位置：** PDF p.4 / State 第5项。

它比较 C 个类别上的完整分布，不只比较最终预测类别。两个模型都预测猫，也可能对狗、虎等类别的概率分配差很多。

**代码展开式：**

\[
p_s^\tau=\operatorname{softmax}(z_s/\tau),\quad
p_t^\tau=\operatorname{softmax}(z_t/\tau),
\quad D=\tau^2\sum_c p^\tau_{t,c}
\log\frac{p^\tau_{t,c}}{p^\tau_{s,c}}.
\]

代码调用顺序是 criterion(student_logits,teacher_logits)，但 PyTorch KLDivLoss 的第二个参数是目标分布，因此计算方向为 **KL(teacher || student)**。默认 τ=4，含 τ² 缩放。以上展开来自代码，不是 PDF 单独列出的第15个公式。

**形状：** [B,C] 的元素级 KL 沿 C 求和，保留 [B]；跨教师组织成 [B,M]。

**上台讲法：** “这个量表示学生还没有学会多少教师输出关系。”

## Eq. (5)：把五类信息装入 state

\[
s_i^m=
[f_i^{T_m}\Vert z_i^{T_m}\Vert
\mathcal L_{CE}^{T_m}\Vert cos_i^{T_m}\Vert KL_i^{T_m}].
\]

**位置：** PDF p.4。

前三项描述教师自身：表示、预测分数、对正确标签的拟合。后两项描述教师与当前学生的关系。双竖线表示拼接，不是相乘或求平均。

**维度：** 一位教师 [B,d_m+C+3]；所有教师联合输入宽度为 Σd_m+M(C+3)。实际四教师 CIFAR 例子为 384+384+256+256+4×103=1692。

**注意：** 实际代码顺序为 [cosine,KL,CE,embedding,logits]；数学含义一致，具体模型权重与拼接顺序必须配套。state 在代码中 detach，agent 更新不会通过 state 回传进学生。

**上台讲法：** “既看老师是否可靠，也看老师与当前学生是否匹配。”

## Eq. (6)：把损失取负作为 reward

\[
R_i^m=-H(y_i^S,y_i)
-\alpha D_{KL}(y_i^S,y_i^{T_m})
-\beta D_{dis}(F_i^S,F_i^{T_m}).
\]

**位置：** PDF p.4 / Reward。

损失越小，负损失越接近0，因此 reward 越大。论文为同一样本的每位教师写一个 reward，整个 batch 为 [B,M]。它不是准确率、不是验证集性能提升，也没有在此定义“当前损失减训练前损失”。

**例子：** 第一张图对三位教师为 [-1.1955,-1.6252,-4.4066]。

**主要边界：** 学生 CE 在同一样本的各教师间是公共项；它不能单独对老师排序。若后续做跨教师 min-max，公共平移还会被消去。代码实际 reward 是先按教师权重聚合后的 [B]，和原式维度不同。

**上台讲法：** “论文用分类与模仿损失共同构造反馈，这是训练代理目标，还不是泛化收益的直接度量。”

## Eq. (7)：论文称为 PG 的 agent 更新

\[
\theta_m\leftarrow\theta_m-\eta\sum_{i=1}^{B}
\bar R_i^m\nabla_{\theta_m}\pi_{\theta_m}(s_i^m),
\quad m=1,\ldots,M.
\]

**位置：** PDF p.4。

**作者意图：** 利用反馈调整策略，增强有利决策、削弱不利决策。η 是 agent 更新步长。

**必须保留的歧义：** 印刷式写的是策略输出的梯度，没有完整写出动作 a、其采样分布或 log 概率；策略又输出连续权重向量。若直接照常见随机 PG 理解，缺少必要定义；不能自行把它改成标准 REINFORCE 再说是作者实现。

为了比较，常见 score-function 形式可写为 \(+\eta\sum_i A_i\nabla_\theta\log\pi_\theta(a_i|s_i)\)，但这是解释参照，**不是本文原式**。还需要考虑最大化 reward 与最小化 loss 的符号约定。

**代码对应：** 当前固定提交使用标签全1、reward加权的 BCE 更新最终权重，两者不是明显等价的表达。具体分析见代码材料。

**上台讲法：** “论文将其组织为策略梯度框架；公开实现的目标函数需要单独说明，不能仅凭 PG 这个名称推断其计算。”

## Eq. (8)：min-max 与居中

\[
\bar R_i^m=
\frac{R_i^m-\min_kR_i^k}{\max_kR_i^k-\min_kR_i^k}
-\frac1M\sum_{k=1}^{M}R_i^k.
\]

**位置：** PDF p.4；已对照原页图像。

第一部分在同一样本的教师维做 min-max，强调相对好坏。配文希望居中后能得到正负反馈，但印刷式减的是原始 reward 均值，混用了两个尺度。

**数值检查：** R=[-1.1955,-1.6252,-4.4066]，min-max=[1,.8662,0]，原均值≈-2.4091，相减后全部为正：[3.4091,3.2753,2.4091]。

在 CE/KL/MSE 非负时，R≤0，因此按字面式确实不能产生配文描述的负反馈。“减归一化后的均值”可产生正负值，但只是候选修正。分母为0时如何处理，PDF也未明确。

**代码对应：** 用 batch 内 reward 均值/标准差做 z-score，再 clamp 到 [0,1]；没有按这条跨教师式子执行。

**上台讲法：** “作者想消除 reward 尺度差异并保留相对反馈，但原文公式和说明不完全吻合，复现要以对应版本进一步核对。”

## Eq. (9)：confidence-aware 单教师权重

\[
w_m^{conf}=
\frac{1}{K-1}
\left(1-\frac{\exp(\mathcal L_m^{CE})}
{\sum_{j=1}^{M}\exp(\mathcal L_j^{CE})}\right).
\]

**位置：** PDF p.8 / A.1。

CE 越大，softmax(CE) 越大，取1减后教师权重越小。它使用标签质量线索，并非直接用最大 softmax 置信度。

**记号问题：** 此处 K 在该段未充分定义；代码用 teacher_num，即 M。因此讲可执行形式时写为 (1-softmax(CE))/(M−1)，并说明来自代码。

**为什么除 M−1：** M 位教师的“1−softmax”之和为 M−1，除后才得到和为1的分布。

**例子：** M=3、CE=[.3567,.6931,1.8971]，得到 [.4292,.4009,.1698]。

**边界：** M=1 时分母为0；Fig.2(d)含单教师点，但公开该分支没有自动给出安全处理，不应默认为原样可用。

## Eq. (10)：将单教师权重组成分布

\[
w^{conf}=[w_1^{conf},w_2^{conf},\ldots,w_M^{conf}]
\in\mathbb R^M.
\]

**位置：** PDF p.8。

这是组装向量的定义，不是另一种训练损失。对于 batch，它是 [B,M]。每行表示同一图片的教师相对权重。

**上台讲法：** “把每位教师的可靠性权重组织起来，作为两个知识层次共用的一条规则支路。”

## Eq. (11)：feature gap 分支偏向相似教师

\[
w_f^{div}
=\operatorname{softmax}([cos^{T_1},\ldots,cos^{T_M}]).
\]

**位置：** PDF p.8。

softmax 沿教师维归一化，cosine 越大，权重越大。作者认为较小的表示语义差距有利于模仿。

**例子：** cosine=[.9806,.8000,0]，得到 [.4525,.3778,.1697]。

**限制：** 这是作者采用的启发式与解释，不是本文已独立证实的普适规律。

## Eq. (12)：logit gap 分支偏向尚未对齐的输出

\[
w_l^{div}
=\operatorname{softmax}([KL^{T_1},\ldots,KL^{T_M}]).
\]

**位置：** PDF p.8。

KL 大的教师获得更强输出模仿力度。作者希望补足学生尚未学会的类别关系。

**例子：** KL=[.2126,.0423,.1570]，得到 [.3585,.3024,.3391]。

**限制：** 错误教师同样可能与学生差得远。该支路不能独立保证选择的是好知识，需要和 confidence、learned 分支一起理解。

**上台讲法：** “特征学得近一些，输出补得远一些；这是两个层次采用不同偏好的设计。”

## Eq. (13)：特征权重三分支融合

\[
w_f=\gamma_f^{gen}w_f^{gen}
+\gamma_f^{conf}w^{conf}
+\gamma_f^{div}w_f^{div}.
\]

**位置：** PDF p.8。

learned 分支学习信息组合，confidence 分支约束教师可靠性，feature-divergence 分支表达可匹配性。默认三个 γ 各为1/3。

**例子：** 本例第一张图最终得到 [.3963,.4284,.1753]。

**注意：** 系数为1/3不意味着 learned 分支贡献了最终准确率提升的1/3。贡献还取决于分布差异、梯度、其他支路和交互，需要消融测量。

## Eq. (14)：输出权重三分支融合

\[
w_l=\gamma_l^{gen}w_l^{gen}
+\gamma_l^{conf}w^{conf}
+\gamma_l^{div}w_l^{div}.
\]

**位置：** PDF p.8。

与 Eq. (13) 结构相同，但使用 logit head 与 logit-gap 分支。两个层次共享 confidence 规则，具有不同的 learned 头、不同的 gap 和可分别设置的融合参数。

**例子：** 第一张图得到 [.4843,.3160,.1997]。两套最终权重送回 Eq. (2)，形成完整闭环。

**代码的 dynamic：** 不开时各1/3；开启后，两组可训练的3维参数分别经过 softmax，产生 γ_l、γ_f。这是三分支融合比例的学习，和“每个样本动态产生教师权重”不是同一概念；即使关闭 dynamic，W 仍可逐样本变化。

## 最后用一条顺序记住 14 式

1→2：从单教师目标到多教师目标。  
3→5：构造 state。  
6→8：定义反馈与 agent 更新的论文写法。  
9→12：构造固定规则支路。  
13→14：融合成最终 action，再代回2。

**汇报重点：** 2、5、6、13、14；**需要提前准备追问：** 7、8的定义歧义，9的 K/M 与单教师边界，4的 KL 实际方向。
