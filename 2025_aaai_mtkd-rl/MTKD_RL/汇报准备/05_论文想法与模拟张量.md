# 从想法到张量：一轮 MTKD-RL 到底发生了什么

本讲解依据用户 PDF 的 Eq. (1)–(14)、Algorithm 1–2。所有小数例子均为**教学模拟**，由同目录 11_模拟张量演示.py 计算，不是论文的中间结果。完整计算见“模拟张量运行结果.json”。源码实例另见“06_实际代码张量流程.md”。

## 1. 先用一句话抓住想法

同一张图片上，教师可能有不同的可靠性，也可能与当前学生存在不同的差距。因此，让一个小网络观察这些信息，分别决定每位教师在“输出分布”和“特征表示”上教多少；再利用训练反馈调整这个小网络。

需要记住三个限定：

- 教师是预训练并固定的，真正被蒸馏的是学生。
- action 是连续权重，不是每次只选一位教师；通常每位教师都参与前向和损失计算。
- 最终权重混合了 learned、confidence、divergence 三个分支；默认等系数融合。完整方法并非仅靠 learned 分支。

位置：PDF p.3–5 / Eq. (2)–(8)、Algorithm 1–2；p.8 / Eq. (9)–(14)。

## 2. 通用张量记号

| 记号 | 含义 | batch 形式 |
|---|---|---|
| B | 一个 batch 的样本数 | 本例 2 |
| M | 教师数 | 本例 3 |
| C | 类别数 | 本例 4 |
| X、y | 输入图片、真实类别索引 | [B,3,H,W]、[B] |
| Zs、Zt[m] | 学生、教师原始 logits | 各 [B,C] |
| Ps、Pt[m] | 对 logits 做 softmax 后的概率 | 各 [B,C] |
| Fs、Ft[m] | 用于特征蒸馏的表示 | 实际可为不同通道数的四维特征图 |
| fs、ft[m] | state 使用的池化向量 | 学生 [B,d]；教师 [B,d_m] |
| State[m] | 第 m 位教师的 state | [B,d_m+C+3] |
| Wl、Wf | 输出层、特征层教师权重 | 各 [B,M] |

[B,M] 中每一行属于一张图片，每一列属于一位教师。它不是类别概率；类别概率的第二维是 C。

## 3. 设定两张图片和三位教师

本例设 T=1、α=1、β=5。T=1 只是便于演算；公开代码的默认温度是 4。

学生概率与真实标签：

~~~text
Ps =
[[0.40, 0.30, 0.20, 0.10],    y[0]=0
 [0.10, 0.20, 0.30, 0.40]]    y[1]=3
shape=[2,4]
~~~

三位教师对第一张图的概率：

~~~text
T1: [0.70, 0.10, 0.10, 0.10]
T2: [0.50, 0.30, 0.10, 0.10]
T3: [0.15, 0.45, 0.30, 0.10]
~~~

对第二张图：

~~~text
T1: [0.10, 0.10, 0.20, 0.60]
T2: [0.10, 0.20, 0.10, 0.60]
T3: [0.10, 0.10, 0.60, 0.20]
~~~

T1/T2 在这两张图上对真实类别给出较高概率，T3 则预测错误。我们故意加入错误教师，便于看清规则的作用；这不是论文额外实验。

## 4. 先计算“教师教得怎么样”

教师 CE 使用硬标签，不使用温度软化：

\[
CE^m_i=-\log P^m_T(y_i).
\]

得到 [B,M]=[2,3]：

~~~text
teacher_CE =
[[0.3567, 0.6931, 1.8971],
 [0.5108, 0.5108, 1.6094]]
~~~

越小表示教师在当前有标签样本上越符合正确答案。它是逐样本质量线索，不能直接称为教师的整体准确率。

教师还提供 embedding 与 logits。这里为便于展示，所有教师 embedding 都设为三维：

~~~text
student_f = [[1,0,0], [0,1,0]]                       [2,3]

teacher_f，按“样本→教师→通道”排列：
样本1：[[1,.2,0], [.8,.6,0], [0,1,0]]
样本2：[[0,1,.2], [.3,.8,0], [1,0,0]]               [2,3,3]
~~~

实际异构教师的通道数可以不同，不能直接 stack 成同一个三维张量。实际代码用 list 保存不同宽度的 state，再沿特征维拼接。

## 5. 再计算“学生跟得上吗”

先假定学生向各教师的特征对齐已完成。在三维教学表示上计算 cosine 与逐通道 MSE：

~~~text
cosine =
[[0.9806, 0.8000, 0.0000],
 [0.9806, 0.9363, 0.0000]]                          [2,3]

feature_MSE =
[[0.0133, 0.1333, 0.6667],
 [0.0133, 0.0433, 0.6667]]                          [2,3]
~~~

cosine 进入 state 和规则权重；MSE 用于特征蒸馏与 reward。这两个量不可混写：方向相近不等于绝对数值相等。

再计算输出差距。为与公开 DistillKL 对齐，本例使用：

\[
D_{i,m}=\sum_c P^m_{T,i,c}\log\frac{P^m_{T,i,c}}{P_{S,i,c}},
\]

也就是 KL(teacher || student)。PDF 的 DKL 参数写法没有充分规定底层 KL API 的方向；汇报代码时明确使用这个方向。

~~~text
KL =
[[0.2126, 0.0423, 0.1570],
 [0.0929, 0.1334, 0.2079]]                          [2,3]
~~~

第一张图 T2 与学生输出最接近，T1 更像“正确但学生尚未充分学会”的教师。

## 6. 拼 state：每位教师一个信息包

论文顺序为：

~~~text
[教师embedding 3维 | 教师logits 4维 | 教师CE 1维 |
 feature cosine 1维 | 输出KL 1维]
~~~

因此每位教师为 [2,10]。三位教师可以表示成 [2,3,10]，送入单一 generator 前展平/拼接为 [2,30]。

这里 teacher_logits=log(teacher_probability)，在 T=1 下 softmax 后恰好恢复前面设置的概率。

对第一张图、第一位教师，信息包是：

~~~text
[1, .2, 0 | log(.7), log(.1), log(.1), log(.1) |
 .3567 | .9806 | .2126]                 共10维
~~~

实际代码改了拼接顺序，但信息类型相同。拼接顺序本身只要与训练时一致即可；改变顺序后直接加载旧策略权重则不成立。

## 7. Action 由三条支路合成

### 7.1 Learned 分支：两套输出

generator 是一个小 MLP。为了能手算，本例直接设定两套 softmax 前的分数，而不训练 MLP：

~~~text
logit_head 分数：[[1,0,-1], [-.5,.4,.8]]
feature_head分数：[[.3,.8,-.2], [.2,.7,-.1]]
~~~

softmax 后：

~~~text
Wgen_l =
[[.6652,.2447,.0900],
 [.1403,.3450,.5147]]

Wgen_f =
[[.3072,.5065,.1863],
 [.2950,.4864,.2186]]
~~~

两套权重不用相同：同一位教师可能适合教输出类别关系，却不适合让学生逐位置模仿特征。

### 7.2 Confidence 分支：降低高 CE 教师的权重

按附录 Eq. (9)，并采用代码中的 M：

\[
W^{conf}_{i,m}=\frac{1-\operatorname{softmax}_{m}(CE^T_i)_m}{M-1}.
\]

~~~text
Wconf =
[[.4292,.4009,.1698],
 [.4000,.4000,.2000]]
~~~

注意这是 (1-softmax(CE))/(M-1)，不是 softmax(-CE)。在 M>1 时每行和为 1。PDF 将分母记为 K−1，公开代码使用 teacher_num−1；按 M 理解需要注明依据。

### 7.3 Divergence 分支：feature 偏近，logit 偏远

~~~text
Wdiv_f = softmax(cosine) =
[[.4525,.3778,.1697],
 [.4289,.4103,.1609]]

Wdiv_l = softmax(KL) =
[[.3585,.3024,.3391],
 [.3161,.3292,.3547]]
~~~

作者解释：feature 相近的老师更容易匹配；输出 KL 较大的老师包含学生尚未学会的信息。后一句依赖教师知识可靠的前提。第二张图的错误教师 T3 也获得最大的 logit-gap 规则权重，正好说明“差距大”本身不等于“知识更好”，需要与置信度等信息结合。

### 7.4 三分支平均，得到最终权重

按 Eq. (13)–(14) 默认设置：

~~~text
Wl =
[[.4843,.3160,.1997],
 [.2855,.3581,.3565]]                               [2,3]

Wf =
[[.3963,.4284,.1753],
 [.3746,.4322,.1931]]                               [2,3]
~~~

每行分别和为 1。对于第一张图，logit 蒸馏最重视 T1，feature 蒸馏最重视 T2。这正是“双层次权重”的具体意思。

## 8. 权重乘到哪里：先保留样本维，再求均值

不是先把 [B] 损失平均掉才乘权重。先对每位教师得到逐样本 KL 和 MSE，再逐元素相乘：

\[
\ell_i=CE^S_i+\sum_mW^l_{i,m}KL_{i,m}
        +5\sum_mW^f_{i,m}MSE_{i,m}.
\]

计算结果：

| 样本 | 学生 CE | 加权 logit KD | 加权 MSE（乘 β 前） | 总损失 |
|---|---:|---:|---:|---:|
| 1 | 0.9163 | 0.1476 | 0.1793 | 1.9602 |
| 2 | 0.9163 | 0.1484 | 0.1525 | 1.8271 |

最终 loss=mean([1.9602,1.8271])=1.8937，是一个零维标量，用于学生反向传播。α、β 控制两种知识总体力度；Wl、Wf 控制这一力度在教师之间如何分配。

## 9. 真正走一次学生梯度

在 T=1 且本轮权重固定时，令 \(\bar P_T=\sum_mW^l_mP^m_T\)，输出分支的逐样本梯度为：

\[
\frac{\partial\ell_i}{\partial Z^S_i}
=(P^S_i-\operatorname{onehot}(y_i))+(P^S_i-\bar P_{T,i}).
\]

第一张图得到：

~~~text
[-.7270, .3669, .2601, .1000]
~~~

梯度下降减去梯度，所以正确类别0的 logit 会上升。特征分支梯度也会把学生表示拉向按 Wf 加权的教师表示。

演示脚本把 logits、三维 embedding 当作独立可训练变量，做学习率0.1、batch mean的一步梯度下降，再重新计算输出：

~~~text
原两样本总损失：[1.9602,1.8271]
新两样本总损失：[1.7559,1.7020]
~~~

这是“独立叶子变量”的教学更新，实际学生通过共享网络参数产生 logits 与特征，不能把这个下降幅度当成真实模型训练结果。

## 10. 论文想法如何闭环

论文 Eq. (6) 对每个样本、每位教师定义 reward：

\[
R_{i,m}=-CE^S_i-\alpha KL_{i,m}-\beta MSE_{i,m}.
\]

在前述快照上，第一张图为：

~~~text
R[0]=[-1.1955,-1.6252,-4.4066]                    [M=3]
~~~

越接近0代表对应组合的损失越低。论文希望让较好反馈增强相应动作。但 Eq. (7)–(8) 未完整定义成一个可无歧义照写的策略梯度算法，详细问题见公式讲解。

特别是 Eq. (8) 按字面计算，第一张图得到：

~~~text
先min-max：[1.0000,.8662,.0000]
减原始reward均值后：[3.4091,3.2753,2.4091]       全为正
~~~

若改成减“min-max后的均值”，则得到 [.3779,.2441,-.6221]，但这是**候选修正，不是原文已确认的定义**。因此汇报论文闭环时可以讲设计意图，不能把这个候选修正冒充作者原式。

## 11. 同一组数值放入公开代码的 reward 路径

代码先在教师维度用 Wl/Wf 聚合损失：

~~~text
reward = -[1.9602,1.8271]                         [B=2]
~~~

再沿 batch 做 z-score。按照 PyTorch 默认样本标准差的口径，本例：

~~~text
z-score = [-.7071,+.7071]
clamp到[0,1] = [0,.7071]
~~~

这里比较的是“两个样本谁的总损失低”，不再是“同一图片的三位教师谁更适合”。这个维度差别是理解论文与代码的核心。公开代码随后对两套最终 action 做 reward 加权、标签全为1的 BCE；具体张量和梯度见下一份材料。

## 12. 上台可以用的收束句

“这个方法将教师选择从一个全局排名问题改成逐样本、分知识层次的分配问题。state 告诉策略老师可靠吗、学生差多少；action 决定输出和特征分别学多少；学生按加权蒸馏目标训练。论文希望通过反馈让权重进一步改善，不过公开代码的反馈维度与更新目标和论文公式存在差异，需要分开讲。”
