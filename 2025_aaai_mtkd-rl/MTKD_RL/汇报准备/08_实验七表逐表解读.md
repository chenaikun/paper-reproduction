# 实验部分：七张表分别证明到哪一步

依据用户 PDF p.5–7，已对照原页图像。准确率和 mAP 两数相减用“百分点”；分割表未标指标名，使用“表内得分单位”。最高报告值不等于统计显著。论文结果与 README 的另一组 dynamic 数值分开，以下均用 PDF 表格。

## 实验先看什么

整套证据可分四层：

1. Table 1–3：完整方法能不能提高分类结果？
2. Table 4–5：分类预训练的收益能不能迁移？
3. Table 6：为什么有用、用复杂 RL 是否必要、代价多少？
4. Table 7：能否与更强的蒸馏损失组合？

图2补充超参、损失项和教师数量；它不单独证明 RL 净贡献。

## Table 1：CIFAR-100，多种 CNN 学生是否都受益

**位置：PDF p.5。**

**设置：** 四位固定教师为 RegNetY-400MF、RegNetX-400MF、ResNet-32x4、WRN-28-4；分别蒸馏四种学生。每一列比较同一个学生的训练方法，不能把不同学生之间的分数差归因于算法。

| 方法 | RegNetX-200MF | MobileNetV2 | ShuffleNetv2 | ResNet-56 |
|---|---:|---:|---:|---:|
| Baseline | 77.38±0.23 | 69.17±0.18 | 72.84±0.15 | 72.52±0.27 |
| AVER(KD) | 78.64±0.31 | 71.85±0.27 | 75.77±0.18 | 73.57±0.29 |
| AVER(KD+FitNet) | 79.12±0.28 | 72.67±0.26 | 76.83±0.34 | 73.93±0.16 |
| AMTML-KD | 79.46±0.45 | 72.89±0.36 | 76.93±0.26 | 74.21±0.33 |
| AEKD | 79.22±0.37 | 72.82±0.42 | 77.08±0.21 | 74.02±0.39 |
| CA-MKD | 80.28±0.26 | 74.16±0.32 | 78.09±0.17 | 75.17±0.24 |
| MMKD | 80.15±0.41 | 74.35±0.34 | 77.87±0.20 | 75.26±0.27 |
| MTKD-RL | **80.58±0.29** | **74.63±0.35** | **78.39±0.14** | **75.35±0.33** |

**按四层读：**

- Baseline→AVER(KD)：单纯引入多个教师的输出知识已经有收益。
- AVER(KD)→AVER(KD+FitNet)：表示知识在这些设置中还提供额外信息。
- 等权→自适应方法：样本相关的权重具有研究价值。
- 最强已有方法→本文：这是本文新增机制真正面对的增量，分别只有0.30、0.28、0.30、0.09个百分点。

| 学生 | 本文比无蒸馏高 | 比等权双损失高 | 比该列最强非本文方法高 |
|---|---:|---:|---:|
| RegNetX-200MF | 3.20 | 1.46 | 0.30 |
| MobileNetV2 | 5.46 | 1.96 | 0.28 |
| ShuffleNetv2 | 5.55 | 1.56 | 0.30 |
| ResNet-56 | 2.83 | 1.42 | 0.09 |

以上差值均由表格相减。表注说明3次运行，但 ± 未明确是 SD、SE 或其他量。因此不能说四列都“显著优于”最强基线。

**值得指出的现象：** 教师本身的报告准确率约78.9–79.6，RegNetX-200MF 学生蒸馏后为80.58；单教师准确率不是学生多源学习效果的硬上界。但这不表示任意弱教师组合都能超过教师。

**上台30秒：** “表1说明完整方法在四种学生上都有最高报告均值，跨架构方向比较一致。不过相比无蒸馏的大幅提升中，有很大一部分是普通蒸馏本身的收益；相比最强权重基线的新增幅度是0.09到0.30个百分点，需要重复结果进一步确认。”

## Table 2：ImageNet CNN，规模扩大后是否仍成立

**位置：PDF p.6。**

**设置：** 四教师 ResNet-50、ResNet-101、WideResNet-50-2、ResNeXt-50(32×4d)；学生 ResNet-18/34。

| 方法 | ResNet-18 | ResNet-34 |
|---|---:|---:|
| Baseline | 70.35 | 73.64 |
| AVER(KD) | 71.52 | 75.32 |
| AVER(KD+FitNet) | 71.56 | 75.55 |
| AMTML-KD | 71.89 | 75.68 |
| AEKD | 71.67 | 75.66 |
| CA-MKD | 72.38 | 75.87 |
| MMKD | 72.33 | 76.06 |
| MTKD-RL | **72.82** | **76.77** |

**主要结论：** 不只在小图片分类上有效；ImageNet CNN 两个学生也获得更高报告值。

**正确比较：**

- ResNet-18：比 Baseline高2.47；比双损失AVER高1.26；比最强非本文CA-MKD高0.44个百分点。
- ResNet-34：相应为3.13、1.22、0.71。
- 论文配文选MMKD比较时，ResNet-18差值是0.49；这个数不是“超过该列最强方法”的幅度，因为CA-MKD 72.38高于MMKD 72.33。

**边界：** 没有重复误差；Params/FLOPs描述学生架构，不能据此推断蒸馏训练总成本。表格也没有直接展示权重行为，所以“权重更有意义”仍是解释。

**上台30秒：** “表2把方法从CIFAR扩展到ImageNet。两种ResNet学生分别达到72.82和76.77，超过各行最强对照0.44和0.71个百分点，支持大规模分类可用性。”

## Table 3：ImageNet ViT，是否只适用于 CNN

**位置：PDF p.6。**

**设置：** 教师 CaiT-S24、DeiT-Small、DeiT-Base；学生 DeiT-Tiny、CaiT-XXS24。

| 方法 | DeiT-Tiny | CaiT-XXS24 |
|---|---:|---:|
| Baseline | 72.23 | 77.32 |
| AVER(KD) / 表中AVER | 73.87 | 78.36 |
| AVER(KD+FitNet) | 73.98 | 78.27 |
| AMTML-KD | 73.68 | 78.57 |
| AEKD | 73.72 | 78.44 |
| CA-MKD | 74.12 | 78.65 |
| MMKD | 74.35 | 78.42 |
| MTKD-RL | **75.14** | **79.22** |

**主要结论：** 框架在论文给出的 Transformer 设置中也能工作。

**关键数字：** 相比 Baseline，高2.91和1.90；相比各自最强非本文方法，高0.79和0.57个百分点。后者最强对照是CA-MKD，并非MMKD。

**一个有用观察：** CaiT行的AVER(KD+FitNet)略低于只用KD的AVER，提示特征知识并不自动有利；它需要适配和合理强度。但单个结果无误差，不宜过度解释这个0.09差值。

**不能说明：** 本文已覆盖所有ViT、任意跨CNN/ViT教师池、跨模态蒸馏或语言模型。公开仓库本次核实的是CIFAR路径，没有实际执行这张表的ImageNet/ViT训练。

**上台30秒：** “表3检验的是骨干类型扩展。DeiT与CaiT两个学生都有更高结果，说明思路不局限于CNN，但还不能外推到任意架构组合。”

## Table 4：检测迁移，分类预训练是否只刷分类分数

**位置：PDF p.6。**

这里不在检测任务里重新执行整套RL蒸馏，而是把普通ImageNet预训练骨干与本文蒸馏预训练骨干，分别放入检测器并微调。

| 骨干 | 检测器 | Baseline mAP | MTKD-RL mAP | 增量 |
|---|---|---:|---:|---:|
| ResNet-18 | Mask-RCNN | 34.1 | 35.1 | 1.0 |
| ResNet-18 | Cascade-RCNN | 36.5 | 37.7 | 1.2 |
| ResNet-18 | RetinaNet | 31.6 | 32.7 | 1.1 |
| ResNet-18 | Faster-RCNN | 33.5 | 34.7 | 1.2 |
| ResNet-34 | Mask-RCNN | 37.6 | 39.0 | 1.4 |
| ResNet-34 | Cascade-RCNN | 39.6 | 40.8 | 1.2 |
| ResNet-34 | RetinaNet | 35.2 | 36.9 | 1.7 |
| ResNet-34 | Faster-RCNN | 37.0 | 38.5 | 1.5 |

**主要结论：** 相对普通预训练，表征收益可以迁移到多种检测器。

ResNet-18平均增量1.125，ResNet-34为1.45个百分点；论文近似报1.1和1.5。

**重要边界：** 没有AVER/CA-MKD/MMKD蒸馏骨干的下游对照，因此不能证明这些迁移收益是RL独有，也不能称“检测上击败其他多教师方法”。Mask-RCNN这一行在此表报告的是mAP，不能自行解释成该表额外验证了实例分割mask AP。

**上台30秒：** “表4把分类预训练骨干放到四类检测器，八组结果方向一致，说明不是只提高分类读出头。不过它只对比普通预训练，所以支持迁移价值，还不能隔离RL特有收益。”

## Table 5：语义分割，像素任务是否也受益

**位置：PDF p.6。**

ResNet-34骨干、两个分割头、三个数据集。

| 分割头 | 方法 | Cityscapes | ADE20K | COCO-Stuff |
|---|---|---:|---:|---:|
| DeepLabV3 | Baseline | 76.34 | 36.08 | 29.97 |
| DeepLabV3 | MTKD-RL | **77.42** | **37.07** | **31.82** |

**主要结论：** 表列分割设置均有迁移收益，跨数据集和分割头方向一致。

**为什么不写mIoU：** 该表与相关段落未明确标注指标名。虽然语义分割常用mIoU，汇报应称“分割得分”并注明需确认，不能把惯例补成作者已写事实。

**不能说明：** 优于强KD迁移基线；也没有直接测量“像素级特征更好”的机制。ADE20K/COCO-Stuff完整设置的可复现性不足。

**上台30秒：** “表5进一步扩展到语义分割，三个数据集、两个分割头都报告提高。它与表4共同支持表征迁移，但对照范围和指标报告仍需补充。”

## Table 6(a)：换更复杂的 RL，结果会更好吗

| 优化方法 | 报告准确率 |
|---|---:|
| PG | **78.39±0.14** |
| DPG | 78.16±0.11 |
| DDPG | 78.05±0.22 |
| PPO | 78.28±0.08 |

**主要体现：** 在作者测试的替代优化器中，简单PG已经给出最高均值，作者据此选择它。

**不能说：** PG显著优于PPO，或者四者等效。只有均值和未充分定义的±，并未做显著性/等效性检验。公开仓库当前代码的BCE更新还需与这些优化器实验版本对应，不能假定当前主脚本包含全部表列算法。

## Table 6(b)：联合信息有没有用

| 组件 | 准确率 | 比等权高 |
|---|---:|---:|
| AVER | 76.83±0.34 | — |
| 教师表现：feature、logit、CE | 77.84±0.17 | 1.01 |
| 师生gap：cosine、KL | 77.46±0.21 | 0.63 |
| All | **78.39±0.14** | 1.56 |

**主要体现：** 只用教师信息和只用匹配信息均有收益，联合设置最高，与作者的互补性动机一致。这是讲方法必要性时最该展示的表。

**边界：** 配文说分析state/action构成，未充分说明是不是只改了state、是否也改固定规则。它不是“保持一切相同只去掉RL”的消融。因此不能把1.56个百分点全部归功于RL。

## Table 6(c)：准确率要付出多少资源

| 方法 | 单epoch时间 | 显存（沿用原表G） | 准确率 |
|---|---:|---:|---:|
| Baseline | 29 s | 2.3 G | 72.84±0.15 |
| AVER | 41 s | 2.8 G | 76.83±0.34 |
| CA-MKD | 54 s | 2.9 G | 78.09±0.17 |
| MTKD-RL | 47 s | 3.2 G | 78.39±0.14 |

**主要体现：** 在这个小规模设置里，性能、时间、显存形成具体权衡。

- 对等权：时间约+14.6%，显存+14.3%。
- 对CA-MKD：时间约−13.0%，显存约+10.3%。
- 对无蒸馏：时间约+62.1%，显存约+39.1%。

百分比均由表格计算，基准不同不能混说。环境为RTX4090、ShuffleNetV2/CIFAR-100、单epoch；不代表ImageNet全训练、教师预训练和全部调参的总成本。

**上台60秒概括整张表6：** “这张表回答三个问题：优化器方面简单PG足够；组件方面联合信息最好；资源方面相对等权增加约15%单轮时间。但这三块证据还不能替代同信息、同算力的非RL对照，所以我接受完整组合有效，对RL本身必要性保持谨慎。”

## Table 7：框架能否接上更强的蒸馏损失

**位置：PDF p.7。**

| ResNet-18 / ImageNet | Baseline | MTKD-RL | +DIST | +ND |
|---|---:|---:|---:|---:|
| Acc@1 | 70.35 | 72.82 | 73.29 | **73.61** |

**主要体现：** 教师权重框架可与改进蒸馏损失组合；相对基本MTKD-RL，分别再提高0.47、0.79个百分点。

**边界：** 表中+ND是否在+DIST上继续叠加未明确，不能把列当成确定的累计路线；也缺少“等权+同样损失”的对照，不能确认两种改进具有额外协同效应。

**上台30秒：** “表7说明本文关注教师权重，与改良单教师蒸馏目标具有可组合性。它提供了扩展接口，但还没有完整测量二者的交互贡献。”

## 补充 Fig. 2：通常会被老师追问的四件事

1. α扫描：所测点中α=1较好。不要从曲线上估读未标的小数。
2. β扫描：所测点中β=5较好，继续加大到10下降，说明特征约束存在强度权衡。
3. Loss项：logit-only、feature-only、both相对Baseline分别+4.14、+3.61、+5.55个百分点，支持两层知识互补。
4. 教师数：当前组合M≈4后趋于平台；未控制说明教师加入顺序，因此不能说“四个老师普遍最好”。

## 汇报时实验部分的完整收束

“主结果支持完整方法在所列分类设置中更好；迁移结果支持预训练表征有下游价值；消融支持组合线索和双层次蒸馏有用；开销和损失替换给出实用性参照。仍缺少的最关键证据是：同状态、同规则、同容量、同预算下，RL更新究竟比直接学习权重多带来多少收益。”
