## 1. 五个概念，一句话一个

1. **MDP**：`(S, A, P, R, γ)`，在状态 `s` 选动作 `a`，环境给回报 `r` 并转到 `s'`。
2. **策略** `π_θ(a|s)`：从状态到动作（或其概率分布）的映射，`θ` 可学习。
3. **回报** `G_t = r_t + γr_{t+1} + ...`：从此刻起拿到的折扣累积奖励。**RL 优化的是它，不是单步 reward。**
4. **价值** `V^π(s)`（这个状态平均能拿多少）、`Q^π(s,a)`（在这个状态做这个动作平均能拿多少）。
5. **目标**：`J(θ) = E_{τ~π_θ}[G]`，找 `θ` 让期望回报最大。

**和你熟悉的监督学习的唯一区别**：没有"正确答案"这个标签，只有"你刚才做得怎么样"这个分数。
所以没法直接算梯度，只能"试 → 拿分 → 按分数调整"。

---

## 2. 策略梯度：全部内容就这三行

对 `J(θ) = E_{a~π_θ}[Q(s,a)]` 求导，用 log-derivative trick：

```
∇_θ J = E[ ∇_θ log π_θ(a|s) · Q^π(s,a) ]
```

含义：**回报高于平均的动作，提高它的概率；低于平均的，降低。** 就这一句话。

用蒙特卡洛样本估计（一个 batch 内平均），并且把 `Q` 换成 `G`，就是 **REINFORCE**：

```
∇_θ J ≈ (1/B) Σ_i  G_i · ∇_θ log π_θ(a_i | s_i)
```

### baseline 为什么能减、且不减偏差

把 `Q(s,a)` 换成 `Q(s,a) - b(s)`，只要 `b` 与动作 `a` 无关：

```
E[ ∇log π(a|s) · b(s) ] = b(s) · ∇_θ Σ_a π(a|s) = b(s) · ∇_θ 1 = 0
```

期望不变（**无偏**），但方差大幅下降。最常用的 `b(s) = V(s)`，于是得到 **advantage**：

```
A(s,a) = Q(s,a) - V(s)    # "这个动作比该状态的平均水平好多少"
```

工程上偷懒的做法：`b` 用回报的滑动平均，甚至用同一批样本里其他动作的平均回报。
**底座论文 Eq.(8) 用的就是这个偷懒版**：同一个样本内，拿这位教师的回报减掉所有教师回报的均值。
严格说这不是真正的 baseline（它是"跨教师"而不是"跨时间"），但这正是它把"哪个教师更好"这件事编码进梯度的方式 —— 也是你可以改进/做 ablation 的点。

> 小提醒：论文 Eq.(7) 写的是 `∇θ πθ`，实际实现都是 `∇θ log πθ`（训练框架里叫 log_prob）。
> 读论文看到这种写法不用慌，按代码理解即可。

| Eq.(7) `θ ← θ - η Σ R̄ ∇π` | 策略梯度 | REINFORCE + 样本内跨教师减均值当 advantage |

**最容易被误解的一点**：它不是"边推理边决策"，而是**每训一个 batch，就让策略网络给一遍权重**。
学生和策略网络是交替优化的，环境（数据集）本身是静止的 —— 所以这根本不是标准 RL 环境。

## 4. 关键洞察：这里的 RL 其实是"双层优化"的求解器

这才是你做这个课题最该先想明白的事，比背算法重要得多。

- 标准 RL：环境会因为你动作而变化（`s' ~ P(·|s,a)`），所以要考虑探索、时序信用分配、on/off-policy。
- **你这里**：数据集固定，动作只影响"这一次学生怎么训"。没有状态转移 → 本质是 **情境式老虎机（contextual bandit）**，
  单步决策、`γ=1`、无 episode 内信用分配问题。
- 那为什么还要用 RL？因为目标 `J(w) = 学生用权重 w 训完之后的验证性能` 这个函数：
  1. **对 w 不可导**（mAP 不可微；就算用 loss，中间隔了一整个训练过程）；
  2. **是二层的**：内层"学生按 w 训练几步"，外层"评价 w 好不好"。
  这类问题属于 **bilevel / meta-learning**，RL（尤其是 PG）只是它的一个**无梯度求解器**。

所以选型逻辑就清楚了：

| 你的情况 | 该用什么 |
|---|---|
| 动作连续（4 维权重） | 策略梯度 / DDPG |
| 动作离散（3 种模式、或 K 组权重码本） | DQN 可以，PG 也可以 |
| 目标不可导、数据固定、单步 | **PG（REINFORCE + baseline）就够** —— 底座论文的选择 |
| 想显式建模"训几步再评价" | 那是 MAML / 元学习，另一条路（MMKD 走的就是这条） |

**结论：主方法用 PG。DQN 只用来做"离散动作"的对照实验。**

## 5. DQN 专章（只为看懂你提案里的那段）

### 5.1 从 Q 学习到 DQN

- 最优动作价值满足贝尔曼最优方程：`Q*(s,a) = E[ r + γ · max_{a'} Q*(s',a') ]`
- 把它写成回归目标，用网络 `Q_φ` 去拟合：
  `L(φ) = ( r + γ · max_{a'} Q_target(s',a') - Q_φ(s,a) )²`
- 纯在线学不行，两个工程件救命：
  1. **经验回放**：把 `(s,a,r,s')` 存起来随机抽，打散样本相关性；
  2. **目标网络**：用一份滞后更新的 `Q_target` 算目标，避免"自己追自己"。

### 5.2 纠正你提案里的一个术语

你写"**双目标网络**机制"。准确说法是：

- DQN 有 **online 网络 + target 网络** 两个网络（这叫目标网络，不叫双目标网络）；
- **Double DQN (DDQN)** 的 "double" 指的是：用 online 网络**选**动作、用 target 网络**评估**它，
  `y = r + γ · Q_target(s', argmax_{a'} Q_online(s',a'))`，目的是**抑制 max 带来的 Q 值过估计**。

写论文时这两个概念别混，审稿人一眼能看出来。

### 5.3 为什么 DQN 不能直接输出连续权重

`max_{a'}` 要求动作空间可枚举。4 维连续权重是无穷集合，取不了 max，所以 DQN 天然只能做离散动作。
**这就是你提案里"连续动作空间 + DQN"这个组合不自洽的根本原因。** 两条出路：

- 换算法：DDPG / PPO / 纯 PG（连续）；
- 换动作：把权重离散化成 K 组原型（码本），DQN 选原型 —— 这时"3 种预设模式"才是合法的，而且是很自然的粗码本。

## 6. 训不起来的六个开关（检测任务上尤其重要）

1. **回报尺度**：不同 batch 的 mAP 波动能到 ±5 个点。必须归一化/裁剪，或用相对增量（本 batch 减滑动均值）。
2. **baseline**：没有 baseline，PG 方差大到几乎不收敛。这是唯一必做的技巧。
3. **探索**：连续权重天然带随机性（softmax 采样）；如果输出确定性权重，要加熵正则或噪声。
4. **冷启动**：先等权/固定权重把学生训到能看，再让策略介入 —— 底座论文 Algorithm 1 的第 1、2 步就是干这个，**别跳**。
5. **交替频率**：学生更新太快，策略的回报就全是噪声；太慢则策略学不到东西。常见做法是"一个 epoch 学生 → 一次策略更新"。
6. **reward hacking**：策略会找到"作弊"路径（比如永远给同一个教师高权重，因为它在训练集上好）。
   对策：reward 一定要在**验证集**或**留出场景**上算，或者加权重熵正则防止坍缩。
